正常便签：可打开/跳转/删除（删除与批量删除均有确认弹窗）。
旧版本角标 ⚠：长版本号（YYYYMMDD）与当前不同，提示说明书可能已更新。
失效便签（灰底弱化）：引用原文被删除或改动，无法定位；可打开预览但内容不可查看，引导删除。删除按钮保持危机红可点（与工程一致，不整卡置灰）。失效浮窗右上角同样有 A− / A+ / ⛶ / ☆ / ✕ 五个按钮（缩放字号、最大化、置顶、关闭均可交互），底部保留危机红删除（带确认弹窗）。

便签浮窗 openSticky

便签浮窗由 openSticky(id) 动态生成到顶部 fixed 叠加层（与工程一致），可拖动标题栏、拖右下角缩放、A± 调字号、⛶ 最大化、☆ 置顶、切换 5 色、保存/编辑/删除/关闭；默认只读，点「编辑」或双击正文进入编辑，Ctrl/Cmd+S 保存。
点击左侧列表「打开」弹出真实可交互浮窗；右下角为自动打开的正常便签示例。

导入测试 importNotes / applySceneText

粘贴一份便签/场景 JSON（或点按钮用示例），点击"模拟导入"查看行为：

逻辑：导入时按 longVersion（长号 YYYYMMDD）判断兼容性。
• 有 longVersion 且原文仍能定位 → 正常导入；窜到新位置则自动校准并刷新记载版本号。
• 有 longVersion 但原文被删/改、无法定位 → 标记 lost 导入（灰度、引导删除）。
• 整批无 longVersion（旧格式，连版本号都无法比较）→ 拒绝导入。
• 场景同上：applySceneText 无 longVersion 直接拒绝。
