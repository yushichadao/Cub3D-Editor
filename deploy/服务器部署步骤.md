## 1.5 上传后必做：修正文件权限（否则 web 版资源 404/回退白屏）

> 用 root/SFTP 上传时，新建目录权限往往是 `drwx------`（700），nginx 的 worker
> 用户 `www` 无法进入子目录（如 `web/three/examples/`），请求会静默回退返回
> `index.html`（HTML），导致 ES module 加载报 `MIME type "text/html"`、Three.js
> 引擎启动失败。**每次上传后必须执行：**

```bash
cd /www/wwwroot/139.196.104.56
chown -R www:www .
find . -type d -exec chmod 755 {} +
find . -type f -exec chmod 644 {} +
# 验证 addons 应返回 application/javascript（而非 text/html）
curl -sI http://139.196.104.56/web/three/examples/jsm/controls/OrbitControls.js | grep -i content-type
```

## 2. 注入路径变量（服务器终端执行）

```bash
# nginx 配置
sed -i 's#__DEPLOY_ROOT__#/www/wwwroot/139.196.104.56#g' /www/wwwroot/139.196.104.56/deploy/nginx-manager.conf
cp /www/wwwroot/139.196.104.56/deploy/nginx-manager.conf /etc/nginx/conf.d/manager.conf
nginx -t && systemctl reload nginx

# systemd 单元
sed -i 's#__DEPLOY_ROOT__#/www/wwwroot/139.196.104.56#g' /www/wwwroot/139.196.104.56/deploy/cub3d-manager.service
cp /www/wwwroot/139.196.104.56/deploy/cub3d-manager.service /etc/systemd/system/cub3d-manager.service
```

---

## 3. 创建环境变量文件 `/etc/cub3d-manager.env`

```bash
cat > /etc/cub3d-manager.env <<'EOF'
PORT=3000
# 境外 GitHub 分发填 token；不需要可留空
GH_TOKEN=
# 管理端基础路径（与 nginx location /admin/ 一致）
BASE=/admin
EOF
```

---

## 4. 安装依赖并启动

```bash
cd /www/wwwroot/139.196.104.56/admin
npm install --omit=dev
systemctl daemon-reload
systemctl enable cub3d-manager
systemctl start cub3d-manager
systemctl status cub3d-manager
```
