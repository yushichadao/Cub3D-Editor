# 国内云端配置指引（Cub3D Editor 更新/分发服务）

> 适用：境内服务器（当前 `139.196.104.56`，备案后切换 `cub3d-editor.cn`）。
> 目标：让「更新检测 + 打包分发 + Web 编辑器 + 宣传页」全部可达，且**云端 webroot 目录层级与本地工程完全一致**。

---

## 1. 层级对照（本地工程 ↔ 云端 webroot）

本地工程顶层 → 云端 `/www/wwwroot/139.196.104.56/`。**保持同名同构**：

| 本地工程 | 云端路径 | 作用 | nginx 映射 |
|---|---|---|---|
| `index.html`、`legal-*.html` | `/index.html`、`/legal-*.html` | 站点根：宣传页 + 法律页 | `location /`（try_files） |
| `web/` | `/web/` | Web 编辑器前端 | `location /` |
| `assets/` | `/assets/` | 站点图片/字体等 | `location /` |
| `shared/` | `/shared/` | 三端共用客户端逻辑（updater / update-sources） | `location /` |
| `downloads/` | `/downloads/` | 更新元数据 `update-doc.json` + 安装包 | `location /downloads/`（静态，CORS=*） |
| `admin/` | `/admin/` | 管理后端（server.mjs / public） | `location /admin/`（URI 前缀，与本地目录名一致） |

> 注意：`admin/` 在文件系统里就叫 `admin`，nginx 对外暴露的代理前缀也是 `/admin`（URI 映射，与目录层级一致）。
> 后端 `server.mjs` 通过环境变量 `BASE=/admin` 感知该前缀，二者必须一致。

---

## 2. 服务器前置条件

- Ubuntu 22.04+，SSH 可达（当前 `root@139.196.104.56`）。
- Node.js ≥ 18（后端运行时）。
- nginx（反向代理 + 静态）。
- 开放端口：80（当前 HTTP，HTTPS 待证书）；后端监听 `127.0.0.1:3000`（仅内网）。

```bash
# 服务器初始化（一次性）
sudo apt update && sudo apt install -y nginx
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo mkdir -p /www/wwwroot/139.196.104.56
sudo chown -R www-data:www/data /www/wwwroot/139.196.104.56
```

## 3. 一键部署（从零重建）

仓库已提供 `deploy/deploy.sh`，会把本地工程同步到云端，**层级与本地一致**：

```bash
# 在本地仓库根目录执行
bash deploy/deploy.sh
# 或指定凭证
DEPLOY_USER=root DEPLOY_HOST=139.196.104.56 bash deploy/deploy.sh
```

脚本依次执行：
1. `mkdir -p` 云端目录（downloads / admin / web / assets / shared）。
2. 上传站点根静态（index.html、web/、assets/、shared/、法律页）。
3. 上传 `admin/` 后端（排除运行时隐私目录 `admin/data`）。
4. `--delete` 同步 `downloads/`（更新元数据权威副本，含真实 `update-doc.json`）。
5. 重启 `cub3d-manager` 服务。

## 4. nginx 配置

将 `deploy/nginx-manager.conf` 复制到服务器并重载（监听 80，当前仅 HTTP；证书就绪后启用 443 与 `return 301 https`）：

```bash
scp deploy/nginx-manager.conf root@139.196.104.56:/etc/nginx/conf.d/cub3d.conf
ssh root@139.196.104.56 "nginx -t && systemctl reload nginx"
```

要点：
- `root /www/wwwroot/139.196.104.56;`
- `location /downloads/` → 静态文件服务 + `Access-Control-Allow-Origin: *`（客户端跨域拉更新元数据）。
- `location /admin/` → 代理到 `127.0.0.1:3000/`（后端 BASE 必须 = `/admin`）。

---

## 5. 后端服务（systemd）与国内源救援

后端 `admin/server.mjs` 已内置 `/api/update` 路由并监听 `0.0.0.0:3000`（BASE=/admin）。
要使客户端「国内源」真正可达，需同时满足：

1. **后端进程在跑**：`cub3d-manager` 服务已启动（WorkingDirectory 必须是 `/www/wwwroot/139.196.104.56/admin`，否则 `ROOT/downloads` 与 nginx 静态目录不一致）。
2. **3000 端口开放**（见 3.5）。
3. **更新元数据一致**：后端 `DOWNLOADS` 默认 = `ROOT/downloads`，而 `ROOT` = admin 的上级目录 = `/www/wwwroot/139.196.104.56`，因此默认已指向 `/www/wwwroot/139.196.104.56/downloads`，与 nginx 静态目录**天然一致**；若显式设置 `CUB3D_DOWNLOADS`，必须指向同一目录。

复制 `deploy/cub3d-manager.service` 到 `/etc/systemd/system/`，并创建环境变量文件（**不要硬编码令牌进仓库**）：

```bash
scp deploy/cub3d-manager.service root@139.196.104.56:/etc/systemd/system/
ssh root@139.196.104.56 "cat > /etc/cub3d-manager.env <<'EOF'
ADMIN_TOKEN=<改成强随机串>
BASE=/admin
PORT=3000
GH_REPO=yushichadao/Cub3D-Editor
# CUB3D_DOWNLOADS 默认 = admin 上级/downloads，与 nginx 静态目录一致，通常无需设；
# 若单独指定，必须指向站点根下的 downloads（否则更新元数据错位）
# GH_TOKEN=xxx   # 境外 GitHub Releases 分发需要时填
EOF"
ssh root@139.196.104.56 "systemctl daemon-reload && systemctl enable --now cub3d-manager"
```

客户端侧 `cn.base` 已是 `http://139.196.104.56/admin`，请求路径为 `/admin/api/update`，与后端路由 `/admin/api/update` 对应，**无需再改客户端**。

## 7. 客户端分流（已落地，仅记录）

`shared/infra/update-sources.mjs` 的 `buildFetchOrder(region)` 实现 IP 切换原则：

1. **先连 IP 所在地服务器网站**（境内→`cnDomain`；境外→`intl`）。
2. **网址无法解析 → 换所在地备用**（境内备用 = 境内 IP `cn`；境外备用 = 国际站本身）。
3. **备用也连不上 → 非 IP 所在地服务器**（境内用户→`intl`；境外用户→`cn`）。
4. **最后 githubProxy 兜底**（服务端代理）。

当前境内源用 `http://139.196.104.56`（服务器仅开 80；Android 端已对 `139.196.104.56` 精确放行明文，见 `android/.../network_security_config.xml`）。备案完成后：将 `cnDomain.enabled` 置 `true`、nginx 启用 HTTPS、客户端即可走 `https://cub3d-editor.cn`。

## 8. 备案后切换（平滑过渡）

1. 域名 `cub3d-editor.cn` 解析到 `139.196.104.56`，配置 SSL 证书（Let's Encrypt）。
2. nginx：启用 `listen 443 ssl`、`server_name cub3d-editor.cn`、`return 301 https`。
3. `update-sources.mjs`：`cnDomain.enabled = true`（境内主源自动切到域名）。
4. Android `network_security_config.xml`：域名备案后可移除对 IP 的明文放行（保留全局 HTTPS）。
