> 本書不是一份冷冰冰的功能清單，而是一本**可以跟著學、跟著做、跟著想**的教材。
> 我們假設你從未接觸過三維設計，甚至沒用過專業軟體。我們會像一位坐在你身邊的老師，

## 前言：寫給完全沒接觸過三維的你

也許你開啟這個網頁時，心裡有一點緊張：三維？建模？那不是要學很久的軟體嗎？

請先深呼吸。🙂

你面前這個工具，是一個**純網頁的三維編輯器**——不需要安裝，不需要顯示卡驅動，不需要報班。它把"創造三維世界"這件事，壓縮成"點一點、拖一拖、輸幾個字"的程度。

很多初學者卡在第一步，是因為被一堆術語嚇住了：座標軸、變換、網格、貼圖……其實它們都很生活化：

- **座標軸**，就像你房間裡的"前—後、左—右、上—下"三條隱形尺子；
- **變換**，就是"挪位置、轉個身、放大縮小"；
- **網格**，是地面上的方格，幫你判斷大小和距離；
- **貼圖**，是把一張圖"貼"到物體表面，像給牆上貼桌布。

本書會把這些概念，一個一個拆開，用你能懂的話講清楚。我們不走"先背定義再操作"的老路，而是**先讓你做出東西，再回過頭理解它為什麼是這樣**。這就是"啟發式"。

讀完這本書，你將能夠：
1. 獨立擺放、調整、上色任意圖形；
2. 用文字、圖片、畫筆豐富你的場景；
3. 用快捷鍵把效率提升到"行雲流水"；
4. 完成從房子、標語到徽標的完整作品。

準備好了嗎？我們先花五分鐘，認準你手上的這一版。

## 第0章 四種形態與本書讀法

在動手之前，請先花三分鐘確認：**你現在用的是哪一種形態？** 這決定了後面每一章裡，你該看哪一條標註。

### 0.1 三個發行版本，四種使用形態

本工具釋出了**三個版本**，但因為網頁版會自動適應裝置，實際使用中一共是**四種形態**：

| 形態 | 怎麼得到它 | 如何確認自己在用它 |
| --- | --- | --- |
| 🖥️ **網頁·滑鼠** | 瀏覽器開啟線上地址 | 螢幕上有滑鼠指標；「鍵盤快捷鍵」幫助區在「設定 → 快捷操作」彈窗裡顯示（不常駐於任何面板） |
| 📱 **網頁·觸屏** | 手機/平板瀏覽器開啟同一個地址 | 底部工具條出現「框選」「全選」按鈕；有「手勢操作」幫助表 |
| 💻 **PC 版** | 下載 `.exe` 安裝或解壓後執行 | 視窗右上角有自繪的「最小化 / 最大化 / 關閉」 |
| 🤖 **Android 版** | 下載 `.apk` 安裝 | 底部有「框選」「全選」；按手機返回鍵會彈出退出確認 |

💡 **網頁版是自動判斷的**：它檢測你的裝置是"精確指標（滑鼠）"還是"粗略指標（手指）"，然後自動切換到對應模式，**你不需要做任何設定**。

⚠️ 若你想在電腦瀏覽器裡**預覽觸屏版**長什麼樣（例如做教學演示），可在網址後面加 `?touch`，例如：
[`https://yushichadao.github.io/Cub3D-Editor/?touch`](https://yushichadao.github.io/Cub3D-Editor/?touch)。反之，Android 版預設恆為觸屏佈局。

| 螢幕取色（按鈕名「螢幕取色」，觸屏端實際僅在畫布內取樣） | ✅ 取螢幕任意處 | ✅ 僅畫布內取樣 | ✅ 取螢幕任意處 | ✅ 僅畫布內取樣 |
| 退出時儲存確認（關閉視窗 / 退出） | ✅ | ✅ | ✅ | ⛔（走返回鍵確認） |
| 手機返回鍵逐層退出確認 | ⛔ | ⛔ | ⛔ | ✅ |
| 離線使用 | ⛔ 需聯網 | ⛔ 需聯網 | ✅ 完全離線 | ✅ 完全離線 |

### 0.3 最核心的差異：手指沒有"右鍵"和"滾輪"

四種形態裡，真正需要你改變肌肉記憶的，其實只有一件事：**輸入方式**。

滑鼠有三個獨立訊號（左鍵、右鍵、滾輪），手指只有一個（按下-移動-抬起）。所以觸屏必須用**手指數量**來區分意圖：

| 你想做的事 | 🖥️💻 滑鼠（網頁·滑鼠 / PC） | 📱🤖 觸屏（網頁·觸屏 / Android） |
| --- | --- | --- |
| 選中物件 | 左鍵單擊 | 單指輕點 |
| 放置圖形 | 左鍵單擊地面 | 單指輕點地面 |
| 旋轉視角 | **右鍵**拖動 | **單指**拖動空白處 |
| 平移視角 | **中鍵**拖動 | **雙指**一起拖動 |
| 縮放視角 | **滾輪**滾動 | **雙指**捏合 / 張開 |
| 多選 | `Shift` + 左鍵單擊 | 點「全選」，或用「框選」 |
| 框選 | 直接左鍵拖出矩形 | 先點「框選」按鈕，再單指拖 |

💡 **一句話記憶**：**滑鼠看"按哪個鍵"，手指看"用幾根指頭"。**

### 0.4 觸屏端的兩個專屬按鈕

因為沒有鍵盤，觸屏形態（📱 網頁·觸屏 與 🤖 Android）在底部工具條上補了兩個按鈕，它們替代了 `Ctrl+A` 和"拖拽框選"：

- **「全選」**：等價於滑鼠端的 `Ctrl + A`，一鍵選中場景中全部物件；
- **「框選」**：點一下進入框選模式（按鈕變藍），然後單指拖出一個矩形，框住的物件會被一起選中。
  ⚠️ **注意**：框選**完成一次後會自動退出**該模式（按鈕恢復原色）。想再框一次，需要**重新點一下**「框選」。這是防止誤觸的設計。

> 🤖 **Android 版限制**：「框選」「全選」兩個按鈕只在**選擇 / 變換**模式下可用；當你處於畫筆、文本、橡皮擦等工具模式時，它們會**變灰停用**並提示「需先切換到「選擇/變換」模式」。這是為了避免和工具的點選邏輯衝突，並非功能缺失。

### 0.5 PC 版專屬：把它當"真正的軟體"用

PC 版不只是"套了個殼的網頁"，它額外提供了桌面軟體才有的能力：

- **視窗控制**：右上角自繪的最小化 / 最大化 / 關閉按鈕；
- **拖放匯入**：直接把 `.json` 工程檔案**拖到窗口裡**就能開啟，不用走「匯入」對話方塊；💻 PC 版還支援把**圖片檔案**拖進視窗，拖入即作為圖片物件放置；
- **崩潰恢復與自動儲存**：意外關閉後重開，會彈出「檢測到未儲存的會話」提示，問你是否恢復自動儲存的進度（並顯示當前物件數量）；直接關閉即可放棄，但**仍建議主動匯出**；
- **便籤置頂浮層**：可以把便籤展開為一個**始終置頂**的浮動卡片（頁面內浮層），一邊看別的資料一邊記；
- **便籤**：可在說明書正文中選中文字新增便籤，並把便籤展開為置頂浮層（詳情見第十三篇）。

### 0.6 Android 版專屬：返回鍵與退出保護

Android 版最需要注意的是**手機返回鍵**的行為，它是分層的：

> 按返回鍵 → 若開著便籤，逐個關閉（有未儲存內容會先問你）→ 再關目錄 → 再退出說明書 → 最後才詢問是否退出應用。

退出應用時會彈出確認框，給你三個選擇：**儲存並退出 / 不儲存退出 / 取消**。這是為了防止你辛苦搭的場景被一個誤觸清空。

💻 **PC 版與網頁版**也有"退出時儲存確認"：當你**關閉視窗 / 退出程式**時，若場景尚未儲存，會彈出確認框——PC 版顯示「場景有未儲存的修改 / 關閉前是否儲存？」，網頁版顯示「是否儲存當前場景？未儲存的內容將在退出後丟失。」——並提供三個選項（順序為「取消 / 不儲存 / 儲存」）；若你沒選儲存位置或儲存失敗，還會再次確認是否仍要退出。這與 Android 的"返回鍵逐層退出"觸發時機不同，但目的一致——保護你的作品不被誤丟。

💡 Android 版**沒有「全屏」按鈕**，因為它本身就是全屏執行的應用。

### 0.7 關於"聯網"與"資料安全"

| | 需要聯網？ | 資料在哪？ |
| --- | --- | --- |
| 🖥️📱 網頁版 | 需要（載入頁面時） | 全部計算在你裝置本地完成，**不上傳任何作品資料** |
| 💻 PC 版 | **完全不需要** | 全部在本機 |
| 🤖 Android 版 | **完全不需要** | 全部在本機 |

三種版本都**不會把你的作品傳到任何伺服器**。網頁版聯網只是為了把頁面下載下來，開啟之後的所有創作都在你自己的裝置裡。

## 第1章 重新認識"三維"：從一張照片說起

### 1.1 二維與三維，差在哪？

拿出手機拍一張桌子的照片。照片是**二維**的：它有寬度、有高度，但手指摸上去是平的——它只是"看起來"有立體感。

現在你繞到桌子側面再看一眼。真實桌子是**三維**的：它有寬度、高度，還有**深度**（桌腿往前伸出的那截）。你走動時，看到的形狀會變；照片卻永遠定格。

💡 **一句話記住**：二維是"畫面"，三維是"你能在裡面走動的真實空間"。

### 1.2 這個網頁給你的是一個"三維舞臺"

開啟編輯器，中央那塊畫布，就是一個三維舞臺。你在左側選一個圖形，往"地面"上一點，它就真真實實地"落"在了舞臺裡——可以繞到它背後看，可以把它舉高，可以從上往下俯視。

❓ **想一想**：如果你要給朋友描述"一個紅球在藍盒子左邊"，用二維照片和用三維場景，哪種更不容易誤會？為什麼？

### 1.3 為什麼做成"輕量三端"？

傳統三維軟體（如 Blender、Maya）功能強大，但安裝包動輒幾百兆，介面密密麻麻。本工具把核心能力做成了一套輕量引擎，並封裝成三個版本：

- 🖥️📱 **網頁版**：開啟網址即用，關掉就走，不佔硬碟；
- 💻 **PC 版**：裝一次，之後**完全離線**，還能直接拖放檔案開啟；
- 🤖 **Android 版**：裝進手機，隨時隨地在通勤路上捏個模型。

三者共同的好處：

- 所有計算在你自己的裝置本地完成，**不上傳任何資料**；
- 匯出的是普通 JSON 檔案和 PNG 圖片，方便儲存與分享；
- **工程檔案三端通用**——你在手機上匯出的 `.json`，可以在 PC 版裡接著改。

💡 這一點很重要：**同一份作品可以跨端接力**。手機上有靈感先搭個草稿，回家用 PC 版精修。

✏️ **練一練**：確認你手上的形態（見[第0章](jump:第0章 四種形態與本書讀法)），開啟工具，看到中央畫布和四周的面板即可。先不要急著操作，只是"認識一下環境"。

## 第3章 介面全景：你眼前的五塊天地

### 3.1 頂欄（最上方）

只有選中了某個物件，右面板才"活"起來：改顏色、貼花紋、調不透明度、設變換數值、編輯文本……這是你精細控制作品的場所。

📱🤖 **觸屏端還會多出兩個按鈕**：

- **「全選」**：一鍵選中場景全部物件（替代滑鼠端的 `Ctrl + A`）；
- **「框選」**：點一下進入框選模式，單指拖出矩形選中一片物件。**框完自動退出**，要再框需再點一次。

介面上**不常駐**顯示快捷鍵 / 手勢列表。滑鼠端與觸屏端的對應操作說明，都集中在「設定 → 快捷操作」彈窗裡：

| Slate | 暮金暖黃 | Paper | 晨曦米白 |

💡 你的選擇會被**記住**：下次啟動仍沿用目前主題，不會被系統設定覆蓋。

## 第4章 座標系：網頁上標著 X / Y / Z 的那三根線

這是全書最關鍵的一章。很多三維軟體的勸退，都始於"座標軸看不懂"。我們慢慢來。

### 4.1 先放下"數學座標軸"的包袱

你可能在數學課見過三根軸，還背過"右手法則"。先忘掉它。在本工具裡，**座標軸就是三根帶顏色、帶字母標籤的箭頭**，用來回答一個問題："這個東西在空間裡的哪個位置、朝哪個方向？"

### 4.2 網頁上你實際看到的標註

請開啟"座標軸"顯示（頂欄的 📐 按鈕），你會看到三根箭頭，末端分別寫著 **X、Y、Z**，顏色各不相同。

> ⚠️ **重要**：本書以及本工具**介面上寫的 X/Y/Z，是網頁標註**，它和軟體內部實現用的軸不完全一樣。普通讀者**只看網頁標註即可**，下面的對應關係就是你在螢幕上真實看到的：

| 網頁標註 | 箭頭顏色 | 代表的方向 | 生活化比喻 |
| --- | --- | --- | --- |
| **X** | 🔵 藍 | **前後**（深度） | 你"往前走 / 往後退" |
| **Y** | 🔴 紅 | **左右** | 你"往左移 / 往右移" |
| **Z** | 🟢 綠 | **上下**（高度） | 你"踮腳 / 蹲下" |

也就是說，在這個網頁裡：**Z 軸是朝上的那根（綠色），X 是前後（藍色），Y 是左右（紅色）。**

💡 記住一句口訣：**"藍前後、紅左右、綠上下（Z 頂天）。"**

### 4.3 為什麼"高度"是 Z 而不是 Y？

在不少三維軟體裡高度是 Y。但本工具的**頁面標註**把高度標成了 Z（綠色那根）。這不是你記錯了，是**這個網頁就是這麼標的**。本書從頭到尾都按"網頁標註"來講，你只要認準螢幕上的顏色與字母，就不會亂。

❓ **想一想**：如果讓你重新設計，你會把"高度"標成哪個字母？字母本身只是名字，關鍵是"名字和顏色、方向"三者要對得上。

### 4.4 地面與"高度 = 0"

舞臺底部有一片**網格地面**。地面是"高度為零"的基準：任何東西放在地面上，它的 Z（高度）就是 0；把它舉高，Z 就變大。

在網頁標註下，地面是由 **X（前後）和 Y（左右）** 張成的水平面，公式寫作"Z = 0"。你不用記公式，只要明白：**地面是"踩腳的地方"，往上（綠軸 Z）是升高。**

### 4.5 用身體感受三根軸

站起來，做三個動作：
- 向前一步、向後一步 → 你沿 **X（藍）** 動；
- 向左跨、向右跨 → 你沿 **Y（紅）** 動；
- 踮腳、下蹲 → 你沿 **Z（綠）** 動。

把這記在肌肉裡，後面所有"移動物件"的操作都有了參照。

✏️ **練一練**：開啟座標軸，分別切到"頂視"和"正視"（底欄按鈕），觀察三根箭頭的方向是否和你身體感受一致。頂視時你看到的是 X–Y 平面；正視時你看到的是 X–Z 平面。

## 第5章 動手做：你的第一個三維作品

光看不練假把式。這一章，我們真做一個能截圖發朋友圈的小作品：**一個彩色立方體站在地面上。**

### 5.1 第一步：選圖形

1. 看左面板，找到「3D 圖形」區（📱🤖 觸屏端若面板是收起的，先點邊緣小按鈕展開）；
2. 點第一個「立方體」（或任意你喜歡的立體）；
3. 進入了"放置模式"：
   - 🖥️💻 滑鼠端：游標進入畫布後會有個**預覽跟隨游標**；
   - 📱🤖 觸屏端：手指沒有"懸停"，所以**沒有跟隨預覽**，點哪兒就放哪兒。

### 5.2 第二步：放下來

在中央地面**點一下**（📱🤖 觸屏端為**單指輕點**）。立方體"啪"地落在網格上。恭喜，你的第一個三維物件誕生了。

💡 如果沒看清落點，別急——下一章學"選擇"後隨時能挪。

### 5.3 第三步：選中它

點左面板的「選擇 / 變換」工具，再**單擊**那個立方體（📱🤖 觸屏端為**單指輕點**）。它周圍出現箭頭或邊框，表示"被選中了"。此時右面板亮起。

### 5.4 第四步：給它上色

在右面板「顏色」區：

- 直接點一個**預設色**（比如明亮的橙），立方體立刻變色；
- 想更個性，用自定義顏色中的「選取器」功能。
⚠️ **注意**：若點了"無顏色"或把不透明度拉到 0.1，物體會變透明甚至有點"看不見"，不是消失了，調回來即可。

### 5.5 第五步：挪一挪、轉一轉

保持選中，拖動箭頭移動（藍前後 / 紅左右 / 綠升高），拖圓環旋轉。感受第 4 章學的三根軸。

### 5.6 第六步：儲存成果

頂欄點「截圖」（或 `Ctrl+P`），得到一張 PNG。也可以「匯出」JSON 留底，下次「匯入」繼續改。

✏️ **練一練**：重複以上步驟，做一個"紅立方體在藍球左邊"的小場景，並截圖儲存。你能用身體動作（前/後、左/右、上/下）向朋友描述每個物體的位置嗎？

## 第6章 儲存與分享：截圖、匯出與備份

做出來的東西，當然要留下來、秀出去。本章講四種"存"的方式，以及它們的適用場景。

### 6.1 為什麼"及時儲存"是好習慣

關掉頁面、重新整理、誤觸返回鍵，未匯出的場景就不在了。養成"做完一段就匯出 JSON"的習慣，能救你無數次。

💻 **PC 版與網頁版是個例外**：它們有**自動儲存與崩潰恢復**（預設每 5 分鐘自動儲存一次，保留最近 10 份快照），意外關閉後重新開啟會彈出「檢測到未儲存的會話」對話方塊，詢問是否恢復上次自動儲存的進度（含物件數量）。但這只是"保險繩"，**不能替代主動匯出**。

### 6.2 截圖：給作品拍張照（Ctrl + P）

「截圖」會把當前畫面存成一張 **PNG 圖片**。

- 適合：發朋友圈、做配圖、交給別人"看效果"；
- 建議：截圖前先點頂欄把**座標軸、網格面隱藏**，畫面更乾淨；
- 輸出尺寸就是當前畫布畫素。

**圖片存到哪裡？各端不同：**

| 形態 | 落地方式 |
| --- | --- |
| 🖥️📱 網頁版 | 走瀏覽器**下載**，落到系統「下載」資料夾（手機瀏覽器可能會先彈出"儲存圖片"詢問） |
| 💻 PC 版 | 彈出**系統儲存對話方塊**，你可以自選資料夾和檔名 |
| 🤖 Android 版 | 儲存到應用儲存，並可通過**系統分享**面板直接發給微信 / 相簿 / 其他應用 |

💡 截圖只儲存"樣子"，不包含可再編輯的資料。想以後還能改，要用下面的"匯出"。

### 6.3 匯出場景：把"可編輯的工程"存下來（Ctrl + S / `匯出` 按鈕）

「匯出」生成一份 **JSON 檔案**，裡面記錄了每個物件的位置、顏色、引數……下次「匯入」就能原樣恢復。

- 適合：半成品、需要繼續打磨的作品；
- 檔名一般帶時間戳，建議改名成有意義的（如 `房子_v1.json`）。

落地方式與截圖相同：🖥️📱 網頁版走瀏覽器下載；💻 PC 版彈系統儲存對話方塊（可自選目錄）；🤖 Android 版存入應用儲存並可分享匯出。

> ✅ **重要**：這份 `.json` 是**三端通用**的。手機上匯出的工程，可以直接在 PC 版裡匯入繼續編輯，反之亦然。

💻 **PC 版的檔案儲存（與網頁"匯出"不同）**：PC 桌面端把場景當作**本地檔案**來管，而不是單純的"匯出 JSON"：
- **`Ctrl + S` = 儲存**：直接覆蓋寫入當前開啟的那個本地場景檔案（若還沒存過盤，則彈"另存為"讓你選位置）；
- **`Ctrl + Shift + S` = 另存為**：把當前場景存成一個**新的**本地檔案，原檔案不受影響。
> 網頁·滑鼠端/網頁·觸屏端沒有"當前檔案"概念，`Ctrl + S` 就是 6.3 的"匯出場景"（下載一份 JSON），二者語義不同，請注意區分。

### 6.4 匯入：把工程讀回來（Ctrl + O）

選一個之前匯出的 `.json`，場景重建。⚠️ 匯入會**替換**當前場景，記得先儲存手頭的工作。

各端取檔案的方式：

- 🖥️📱 **網頁版**：點「匯入」，在瀏覽器彈出的檔案選擇框裡挑檔案；
- 💻 **PC 版**與 🖥️ **網頁·滑鼠**端：除了點「匯入」，還可以**直接把 `.json` 檔案拖進視窗**（不支援的檔案型別會提示"僅支援場景檔案"）；💻 **PC 版**額外支援把**圖片檔案**拖進視窗，拖入即作為圖片物件放置；
- 🤖 **Android 版**：點「匯入」，在系統檔案選擇器裡定位到你的 `.json`。

### 6.5 新建：從頭開始（Ctrl + N）

「新建」清空整個場景。危險操作，但配合"先匯出備份"就很安全。

### 6.6 🤖 Android 專屬：返回鍵不會讓你"白乾"

Android 版按返回鍵退出應用時，會彈出確認框，提供三個選項：

- **儲存並退出**：先匯出當前場景再退出（推薦）；
- **直接退出**：不儲存，謹慎使用；
- **取消**：留下繼續編輯。

💡 所以在 Android 上誤觸返回鍵並不可怕——但仍建議養成階段性匯出的習慣。

### 6.7 一套穩妥的備份節奏

> 動手前匯出一次 → 關鍵節點再匯出（用不同檔名）→ 隨時撤銷回退。
> （🖥️💻 滑鼠端按 `Ctrl+Z`；📱🤖 觸屏端點頂欄的「撤銷」按鈕。）

✏️ **練一練**：把你第5章做的"紅立方體 + 藍球"場景，分別用「截圖」和「匯出」各存一份，再用「匯入」讀回，確認內容一致。
進階：如果你同時有手機和電腦，試試**在一端匯出、另一端匯入**，體會工程檔案的跨端通用性。

# 第二篇 操作基礎篇

## 第7章 選擇物件的藝術：單選、多選與框選

在三維世界裡，**"先選中，再操作"**是鐵律。本章把"選中"這件小事講透。

### 7.1 為什麼必須先選

右面板的引數、變換箭頭，都是"針對當前選中物件"的。沒選中，工具就不知道你想改誰。這就像你不能同時給全班同學發同一份只寫一個名字的獎狀——得先點名。

### 7.2 單選：點一下

用「選擇 / 變換」工具，在物件上點一下。它高亮、出現控制元件，表示"選中了"。

- 🖥️💻 **滑鼠端**：**單擊左鍵**；
- 📱🤖 **觸屏端**：**單指輕點**（點完即抬起，不要拖）。

### 7.3 多選：加選第二個、第三個……

| 形態 | 怎麼多選 |
| --- | --- |
| 🖥️💻 網頁·滑鼠 / PC | 按住 `Shift` 再點其他物件，**累加**選中；已選中的再點一下則**取消**那個 |
| 📱🤖 網頁·觸屏 / Android | 沒有 `Shift` 鍵，但可**單指長按**某個物件 —— 未選中則加選、已選中則減選（等價於滑鼠端的 Shift 單擊）；也可改用底欄的「**框選**」圈出一片，或「**全選**」一次全要 |

💡 多選後做變換，所有物件作為一個整體一起動，以它們的"組中心"為基準。

### 7.4 框選：拖個矩形

框選適合"一下子抓一堆"，但兩端起手方式完全不同，這是最容易搞混的一處：

**🖥️💻 滑鼠端（網頁·滑鼠 / PC）**

在**空白處按住左鍵拖出矩形**，框內物件被全選。隨時可用，無需切換模式。

⚠️ 框選必須從"空白處"起手。如果在物件上起手拖動，會變成**移動那個物件**。

**📱🤖 觸屏端（網頁·觸屏 / Android）**

手指拖動預設是"轉視角"，所以必須先告訴程式"我現在要框選"：

1. 點底欄的「**框選**」按鈕，按鈕變藍表示已進入框選模式；
2. **單指拖出**一個矩形，框住想選的物件；
3. 鬆手，選中完成——**此時框選模式會自動關閉**，按鈕恢復原色。

⚠️ **重要**：觸屏端框選是**一次性**的。想連續框第二次，必須**再點一次**「框選」按鈕。這是為了避免你想轉視角時誤框。

### 7.5 全選

一鍵選中場景裡所有物件。配合「清空」或整體變換很方便。

- 🖥️💻 **滑鼠端**：按 `Ctrl + A`；
- 📱🤖 **觸屏端**：點底欄的「**全選**」按鈕。

### 7.6 取消選擇

- **四端通用**：點畫布空白處；
- 🖥️💻 **滑鼠端另可**：按 `Esc` 鍵。

### 7.7 選中提示：螢幕會"告訴你選了什麼"

從本版本起，每一次選擇狀態變化，畫布上方都會浮出一條**輕量提示條**（幾秒後自動消失，不會擋住操作）：

| 情形 | 提示內容 |
| --- | --- |
| 只選中 1 個圖形 | `已選中「立方體」`（顯示該物件的名稱，用方括號「」包裹） |
| 只選中 1 個文本 | `已選中「文本：實際內容」`（物件名 + 冒號 + 文本正文） |
| 選中 2 個及以上 | `已選中 5 個物件`（顯示當前總數） |
| Shift 加選 / 減選 | 每點一次都重新整理為**當前**數量，例如 3 → 4 → 3 |
| 取消全部選擇 | `已取消選中` |

💡 這條提示最實用的場景是**框選**和 **Shift 連點**：你不必逐個數，看一眼數字就知道有沒有多框、漏框。

### 7.8 選中狀態下點工具欄：自動退出選中

選中物件後，如果你點選左面板的以下 **5 個工具**，編輯器會先**自動取消當前選擇**，再進入該工具，並提示 `已退出選中模式`：

- 文本
- 圖片
- 3D 畫筆
- 2D 畫筆
- 橡皮擦

這 5 個工具都是"要在畫布上新落筆"的操作，保留舊選擇只會干擾。

⚠️ 除此之外的工具（各種 3D / 2D 圖形按鈕）在**有選中物件時點選不會生效**——這是刻意的保護，避免你想調引數時誤放了一個新圖形。想放新圖形，請先取消選擇（🖥️💻 按 `Esc` 或點空白處；📱🤖 點畫布空白處）。

### 7.9 選不中？先排查這幾點

1. 是不是還在"放置模式"？先切回「選擇 / 變換」工具；
2. 想選的物件是不是被另一個擋住了？換個視角（底欄）繞到正面；
3. 它是不是透明瞭（不透明度調到最低的 0.1）？先調回來；
4. 它是不是 2D 筆跡？部分畫筆物件需用橡皮或專門邏輯，普通單擊未必選得中。

❓ **想一想**：多選和框選，哪種更適合"精確挑三個不相鄰的物件"？哪種適合"選出一整排"?

✏️ **練一練**：放 5 個不同圖形，練習①單選其中一個 ②Shift 加選到三個（注意看提示條數字變化）③框選一整片 ④Ctrl+A 全選 ⑤點「文本」工具，觀察它自動退出選中。

## 第8章 變換三件套：移動、旋轉、縮放

"變換"是三維創作裡最高頻的動作，本質就是三件事：**挪位置、轉方向、改大小**。

### 8.1 三種變換是什麼

| 變換 | 生活比喻 | 螢幕上的控制元件 |
| --- | --- | --- |
| 平移（移動） | 把杯子從桌左搬到桌右 | 三根帶顏色的箭頭 |
| 旋轉 | 把杯子口轉向你 | 圓圈 / 弧線手柄 |
| 縮放 | 把杯子變大變小 | 方塊手柄 |

### 8.2 平移：順著三根軸拖

選中物件後，會出現紅、綠、藍（網頁標註為 Y紅=左右、Z綠=高度、X藍=前後）的箭頭。

- 拖**紅色箭頭** → 沿 Y（左右）移；
- 拖**綠色箭頭** → 沿 Z（高度）升 / 降；
- 拖**藍色箭頭** → 沿 X（前後）移。

💡 只拖一根箭頭，物件就只在那一個方向上動，不會被帶偏。想自由斜著移，拖箭頭之間的"平面方塊"即可。

### 8.3 旋轉：繞軸轉

切到「旋轉」模式，物件被圓環包圍：

- 拖圓環 → 繞對應軸轉動。例如讓"正面"從朝前變成朝左，就是繞 Z（高度綠軸）轉。

⚠️ **注意**：旋轉是"繞哪根軸"。記住口訣：繞綠軸（Z）轉 = 像原地轉身；繞藍軸（X，前後）轉 = 像點頭；繞紅軸（Y，左右）轉 = 像側歪頭。

### 8.4 縮放：改大小

切到「縮放」，拖手柄放大縮小。預設是**等比**（後面第9章講鎖）。

### 8.5 想要精確？用右側數值

拖拽靠手感，引數靠輸入。右面板裡每個變換都有數字框：

- 位置：X / Y / Z 三個數（網頁標註下即前後 / 左右 / 高度）；
- 旋轉：三個角度；
- 縮放：比例值。

💡 做"對得很齊"的排版時，直接填相同數值，比肉眼拖準得多。

✏️ **練一練**：放一個立方體，先拖箭頭把它移到右上方；再在右邊數值框把 X、Y、Z 都改成整數（如 2, 0, 3），觀察它精確落點。

## 第9章 變換模式與等比縮放

上一章講了動作，本章講"怎麼切模式"和"怎麼鎖比例"。

### 9.1 三種模式在哪切

右面板下方（選中物件後）有「平移 / 旋轉 / 縮放」三個按鈕，也可用快捷鍵（效率篇詳述）。切換後，物件身上的控制元件會變成對應樣子。

### 9.2 等比縮放是什麼

縮放時有個「等比縮放」開關：

- **開啟**：任意方向同步縮放，形狀**不變形**（球還是球，方塊還是方塊）；
- **關閉**：可**單軸拉伸**，比如把球壓扁成橢圓、把方塊拉成條。

⚠️ **注意**：等比縮放欄只在"單選且開啟等比縮放"時才顯示。多選時它被停用（用變換控制元件整體縮放）。

### 9.3 文本不支援等比縮放

選中**文本物件**時，你會發現：

- 右面板的「等比縮放」滑桿整行**隱藏**；
- 「等比縮放」勾選框**隱藏**；
- 模式按鈕裡的「縮放」變成**灰色不可點**（若你正處在縮放模式，會自動切回平移）。

原因：文本是由字號、字型、粗細等排版引數即時生成的貼圖薄板，直接拉伸會導致字形模糊變形。**想改文本大小，請用右面板的「字號」引數**——那是無損的。

### 9.4 什麼時候關掉鎖

想做"壓扁的墊片""拉長的柱子""扁橢圓鏡片"時，關鎖、單軸拖。這是從"標準體"走向"個性體"的鑰匙。

❓ **想一想**：為什麼"壓扁的球"和"標準球"在三維裡是兩種不同的視覺語言？各適合表現什麼物體？

✏️ **練一練**：放一個球體，關掉等比鎖，只沿 Z（高度綠軸）壓到 0.3，得到一個"飛碟 / 扁圓盤"，感受單軸縮放。

## 第10章 撤銷與歷史：大膽試錯的底氣

新手最大的心理障礙是"怕點錯"。這一章給你一顆定心丸。

### 10.1 撤銷與重做

- `Ctrl + Z`：撤銷上一步；
- `Ctrl + Y`：重做。

可以連續多步往回退，也能再往前 redo。

### 10.2 "歷史棧"是什麼

軟體內部記著一個**操作列表**（像瀏覽器的後退記錄）。每做一個重要操作就壓入一條；撤銷就是彈出最後一條。

⚠️ **注意**：歷史有**步數上限**。很早的操作可能被"擠出"列表，退不回去了——所以關鍵節點要匯出 JSON 備份（見[第6章](jump:第6章 儲存與分享：截圖、匯出與備份)）。

### 10.3 什麼進歷史，什麼不進

- **進歷史**：增刪物件、改色、變換、貼圖等"對作品內容的改動"；
- **不進歷史**：單純轉動視角、縮放觀察（這些是"你看的方式"，不改作品本身）。

所以你可以放心轉來轉去觀察，不用擔心把視角變動也記成一堆撤銷步。

### 10.4 大膽試錯的心法

> 每個操作都可撤銷 + 關鍵節點有備份 = 沒有真正的"搞砸"。

把這句話貼在心裡，你就敢亂點了。

✏️ **練一練**：連續做 5 個不同操作（加物件、改色、移動、縮放、刪一個），然後連按 `Ctrl+Z` 看它一步步倒帶，再 `Ctrl+Y` 正放，體會"時間機器"。

### 12.1 2D 是什麼

2D 圖形**沒有厚度**，像一張剪紙，**平躺在地面**上（XY 平面，Z=0）。它適合做符號、地標、裝飾紋樣。

### 12.4 遮擋要注意

2D 貼在地上，3D 物體若壓上來會擋住它；從某些角度看，薄薄的 2D 會"消失"成一條線。需要顯眼時，把它稍微抬高（沿 Z 綠軸）或放在空曠處。

## 第13章 每種 3D 圖形引數詳解（上）：基礎體

> 本節逐個講 10 種最常用立體。每個都按"外觀 / 類比 / 用途 / 貼士"四段，方便你建立直覺。

### 13.1 立方體 box
- **引數**：`長度` / `寬度` / `高度`（三者獨立，可直接做成長方體，不必再關等比鎖去拉伸）。
- **外觀**：六個矩形面的直角體。
- **類比**：快遞紙箱、骰子、磚塊。
- **用途**：建築牆體、臺基，以及一切"方方正正"的東西。
- **貼士**：最穩的"地基"形狀；想做矮牆，把`高度`調小即可，比縮放更精確。

### 13.2 球體 sphere
- **引數**：`半徑`。
- **外觀**：完美圓球。
- **類比**：籃球、星球、泡泡。
- **用途**：頭部、天體、裝飾球。
- **貼士**：球面上貼花紋/圖片最"攤得開"，適合做帶圖示的球。

### 13.3 圓柱 cylinder
- **引數**：`半徑` / `高度`（上下同徑，是真正的正圓柱；想要上下不同徑請改用**筒狀體 barrel**）。
- **外觀**：上下等圓、側壁筆直。
- **類比**：易拉罐、柱子、蠟燭。
- **用途**：樑柱、筒身、塔身。
- **貼士**：與 barrel 的分工要記牢——**cylinder 只管"一個半徑"，barrel 管"兩個半徑"**。

### 13.4 圓錐 cone
- **引數**：`底面半徑` / `高度`。
- **外觀**：圓底、尖頂。
- **類比**：冰淇淋蛋筒、路錐、帳篷尖。
- **用途**：尖頂、指示燈、聖誕樹每層。
- **貼士**：多個 cone 逐層縮小`底面半徑`堆疊，能拼出"分層塔"。

### 13.5 環面 torus
- **引數**：`外環半徑` / `內環半徑`（**直接描述你看到的兩個圈**：外圈多大、中間的洞多大。舊版的"管半徑"已取消）。
- **外觀**：甜甜圈，中間有洞。
- **類比**：呼啦圈、輪胎、戒指。
- **用途**：環形裝飾、管道彎頭、光環。
- **貼士**：`內環半徑`會被自動限制為小於`外環半徑`；兩者越接近，圈就越細，像鐵絲環。

### 13.6 紐結 knot
- **引數**：`半徑` / `管粗`（`管粗`上限自動跟隨`半徑`，約為半徑的 0.4 倍，防止自交成一坨）。
- **外觀**：像麻花辮繞成的環。
- **類比**：繩結、能量符號。
- **用途**：科技感裝飾、徽標主體。
- **貼士**：造型複雜，建議單色或簡單花紋，避免貼圖亂。

### 13.7 正二十面體 icosa
- **引數**：`邊長`（**不是半徑**——直接給出每條稜的實際長度，更符合幾何直覺）。
- **外觀**：20 個等邊三角形拼成的近球多面體。
- **類比**：足球（經典 32 面版的近親）、礦石晶體。
- **用途**：寶石、骰子、低多邊形風格球。
- **貼士**："低多邊形（low-poly）"審美的代表，配純色很高階。

### 13.8 正八面體 octa
- **引數**：`邊長`。
- **外觀**：上下兩個尖、中間鼓成八面。
- **類比**：鑽石切割、雙錐。
- **用途**：水晶、寶石、抽象雕塑。
- **貼士**：旋轉起來光影變化豐富，適合做"焦點裝飾"。

### 13.9 正十二面體 dodeca
- **引數**：`邊長`。
- **外觀**：12 個正五邊形面的球體感多面體。
- **類比**：魔法石、骰子（D12）。
- **用途**：神秘感符號、擺件。
- **貼士**：同樣邊長下，正十二面體看起來比正二十面體"大一圈"，因為它的外接球半徑係數更高。

### 13.10 膠囊 capsule
- **引數**：`半徑` / `圓柱長`（總高 = 圓柱長 + 2 × 半徑）。
- **外觀**：圓柱兩端加半球。
- **類比**：膠囊藥、跑道、保齡球瓶。
- **用途**：人體軀幹簡化、軟管、圓潤柱子。
- **貼士**：比純圓柱"柔和"，做角色或生物時常用。

✏️ **練一練**：用 box + cylinder + cone 拼一個"路燈"：圓柱做杆、box 做燈箱、cone 做頂罩。體會基礎體組合的力量。

## 第14章 每種 3D 圖形引數詳解（下）：特種形狀

### 14.1 正四稜錐 pyramid
- **引數**：`底面邊長` / `高度`（舊版的"邊數"已取消——它本來就該是**正四**稜錐）。
- **外觀**：正方形底面 + 一個尖頂。
- **類比**：埃及金字塔、房頂。
- **用途**：塔、尖頂建築、紀念碑。
- **貼士**：本版本重算了它的法線，四個斜面現在是**清晰的平面明暗**，不再有舊版那種"糊成一團"的光照。

### 14.2 正三稜柱 prism
- **引數**：`底面邊長` / `高度`。
- **外觀**：正三角形截面的直柱。
- **類比**：三稜鏡、路障、屋頂梁。
- **用途**：三角梁、楔塊、科技構件。
- **貼士**：同樣修復了法線，三個側面稜角分明；橫放可作"斜坡塊"。

### 14.3 管道 tube
- **引數**：`跨度` / `拱高` / `管半徑` / `彎曲分段`。
- **外觀**：一段架起來的拱形圓管，兩端落地。
- **類比**：拱橋、彩虹、門形把手。
- **用途**：橋樑、拱門、裝飾飄帶。
- **貼士**：`跨度`是兩端點的水平距離，`拱高`是中間抬起的高度——**兩者的比值決定它是"扁拱"還是"高拱"**。`管半徑`上限會隨跨度/拱高自動收緊，避免管子粗到把拱洞堵死。`彎曲分段`越大越圓滑，越小越有折線感。

### 14.4 迴轉體 lathe
- **引數**：`分段`（≥ 3） / `底面半徑` / `中間半徑` / `最寬半徑` / `高度`。
- **外觀**：一條輪廓線繞中軸轉出來的體（花瓶/陀螺狀）。
- **類比**：花瓶、燈泡、陀螺、高腳杯。
- **用途**：對稱容器、器皿、雕塑。
- **貼士**：三個半徑分別控制**底部、腰部、最鼓處**。想做"花瓶"就讓`最寬半徑` > `中間半徑` > `底面半徑`；想做"陀螺"就反過來。`分段`控制圓周精度，最少 3 段（此時是三稜臺的觀感）。

### 14.5 正四面體 tetra
- **引數**：`底面邊長`。
- **外觀**：4 個正三角面的最小多面體。
- **類比**：三角錐、晶體碎塊。
- **用途**：碎石、低多邊形裝飾、尖銳符號。
- **貼士**：面少稜硬，做"硬核/科技"風很合適。

### 14.6 筒狀體 barrel
- **引數**：`頂半徑` / `底半徑` / `高度`（舊版那個含混的"半徑"已刪除）。
- **外觀**：上下口徑可以不同的筒。
- **類比**：木桶、花盆、紙杯、火箭中段。
- **用途**：容器、機身、蓄水池。
- **貼士**：**這是最靈活的柱狀體**——兩徑相等 = 圓柱；上小下大 = 花盆；上大下小 = 紙杯；把`頂半徑`調到接近 0 就得到圓錐。

### 14.7 半球 dome
- **引數**：`半徑`。
- **外觀**：半個球（上半）。
- **類比**：蒙古包頂、天文臺、鐘形罩。
- **用途**：屋頂、罩子、天象館。
- **貼士**：與 box 組合可做成"帶頂小屋"；翻過來（旋轉）是"碗"。

### 14.8 開口環面 helix
- **引數**：`外環半徑` / `內環半徑` / `主掃掠角`（舊版的"管半徑"已取消，改用與環面一致的內外雙半徑）。
- **外觀**：缺了一口的環——環面被切掉了一段圓弧。
- **類比**：C 形卡扣、開口手鐲、彈簧的一圈。
- **用途**：動態裝飾、漩渦符號、能量環、卡扣結構。
- **貼士**：`主掃掠角`就是"這個環一共轉了多少度"：360° 是完整環面，270° 是經典的 C 形，180° 是半環。**改這一個引數就能從"閉合"平滑過渡到"敞開"**。

### 14.9 正八稜柱 octaPrism
- **引數**：`底面邊長` / `高度`（舊版的"半徑"改為更直觀的邊長）。
- **外觀**：八個豎邊面的直柱。
- **類比**：八邊形立柱、燈塔、井壁。
- **用途**：規整立柱、塔身、基座。
- **貼士**：比圓柱"有稜角"，比 box"圓潤"，折中感好。

### 14.10 立體星 star3d
- **引數**：`外半徑` / `內半徑` / `角數` / `厚度`。
- **外觀**：星形擠出成有厚度的立體。
- **類比**：獎章、星星掛件、勳章、齒輪。
- **用途**：獎勵符號、裝飾主體、Logo。
- **貼士**：`角數`可以遠不止 5——調到 3 是三角星，調大配合"內外半徑接近"就變成**齒輪**。`內半徑`自動限制為小於`外半徑`。

## 第15章 "站"與"躺"：3D 與 2D 的本質差異

### 15.1 體積 vs 面積

- **3D 有體積**：佔空間、能投影、能互相遮擋。它"站"在地面上，有高度（Z 綠軸）。
- **2D 只有面積**：平鋪成一片，厚度為零。它"躺"在地面上（Z=0）。

理解這一點，你就懂了為什麼 3D 物體能"疊羅漢"，而 2D 只能"鋪地板"。

### 15.2 為什麼一個站一個躺

程式碼上，3D 用 `seatOnGround` 把底面落到 y=0（網頁標註 Z=0）；2D 用 `shape2D` 旋轉到 XZ 平面（地面）並貼地。所以：
（注：前文"地面 / XY 平面 / Z=0"是**網頁介面標註**的叫法；這裡的 `y=0` / `XZ 平面`是 **Three.js 內部座標系**的叫法——兩者指的是同一塊地面，只是命名體系不同：Three.js 內部用 Y 軸表示"高度"，對應本書 UI 標註的綠軸 Z；內部 X、Z 軸對應本書 UI 標註的 X（前後）、Y（左右）。）
- 放一個 box，它自然"坐"在地上；
- 放一個 heart，它自然"貼"在地上。

### 15.3 混用技巧

- 想讓 2D "立"起來？把它沿紅軸（Y）旋轉 90°，它就從"躺"變"立"——可做立牌、招牌；
- 想讓 3D "趴"下？旋轉讓它側倒，做"倒下的樹""斜靠的板"；
- 地面符號（箭頭指路）+ 立體建築，是場景最常見的組合。

✏️ **練一練**：放一個 arrow（2D），選中後沿 Y（紅/左右）旋轉 90°，觀察它從"躺地箭頭"變成"立起的指路牌"。這就是"站與躺"的自由切換。

# 第四篇 色彩與材質篇

顏色是作品的"情緒"。本章從"光是什麼"講起，再到 27 種預設、自定義取色、12 種花紋，最後講圖片貼圖與不透明度。

## 第16章 顏色入門：人眼與光的遊戲

### 16.1 顏色不是物體"自帶"的

一個紅蘋果在黑夜裡是黑的——你看到紅色，是因為光打在它上、被"反射"進你眼睛。所以**顏色 = 物體 + 光**。本工具用 `MeshStandardMaterial`（受光材質），場景裡有環境光（強度 1.0）和方向光（強度 2.6），物體才會顯出明暗。

💡 這就是為什麼同一顏色，轉到背光面會"變暗"——不是顏色變了，是光少了。

### 16.2 RGB：螢幕用三原色混合

顯示器用 **紅(R)、綠(G)、藍(B)** 三束光混合出所有顏色。本工具預設色裡的 `0xff0000` 就是"滿紅、無綠藍 = 純紅"。

### 16.3 HSV：人腦挑顏色的直覺

比起 RGB，人更習慣用 **色相(H, 什麼顏色)、飽和度(S, 豔不豔)、明度(V, 亮不亮)** 來選。取色器拖動時，你其實在調 HSV。

- 色相 = 紅橙黃綠青藍紫轉一圈；
- 飽和度低 → 發灰；飽和度高 → 鮮豔；
- 明度低 → 暗；高 → 亮（甚至發白）。

### 16.4 材質的兩個隱藏引數

物體表面有 `roughness`（粗糙/0.6，越大越啞光）和 `metalness`（金屬感/0.0，越大越像金屬）。當前預設偏"啞光塑膠"。你改的是顏色，這兩個一般不動，但知道它們存在，能理解"為什麼不是鏡面反光"。

### 16.5 不透明度：讓光穿過去

顏色之外還有"透不透"。後文第20章詳講，這裡先記：不透明度 1 = 實心，0 = 隱形。

❓ **想一想**：為什麼醫院的牆、手術服多用"低飽和的淺藍/淺綠"？顏色飽和度高低，如何影響人的情緒？

✏️ **練一練**：放一個白球，切到不同視角，觀察它背光面是否變暗。這就是"光塑造顏色"的直觀證據。

## 第18章 自定義顏色：HEX、HSV 與螢幕取色器

### 18.1 HEX 是什麼

HEX 是 `#` 後跟 6 位十六進位制，兩位一組代表 R、G、B。例如品牌色 `#1e90ff`（道奇藍）。想精確復刻某個顏色，直接填 HEX 最準。

### 18.2 選取器怎麼拖

點開右面板的「選取器」按鈕，會彈出一個取色窗，裡面是"大色塊 + 色相條 + HEX/RGB 輸入框"：
- 在大色塊裡點 / 拖 → 選**飽和度 + 明度**（左右管濃淡、上下管亮暗）；
- 拖下面的**色相條** → 調**色相**（紅橙黃綠青藍紫一圈走）；
- 想絕對精確，直接在 HEX 或 R/G/B 框裡填數字最穩。

💡 想找"同色系深淺"，把色相條**固定不動**、只在大色塊裡上下拖（改明度），配出來最和諧。

### 18.3 螢幕取色器（吸管）

有些版本提供"從畫面取色"：點吸管，再到畫面任意處（包括別的物體的顏色、背景）點一下，就採到那個顏色。做"取景於現實"的配色極方便。

### 18.4 什麼是"無顏色"（NO_COLOR）

原始碼裡有 `NO_COLOR = -1` 這個特殊標記。選它，物體**不套用純色著色**（常配合圖片貼圖或特殊材質，呈現"無底色"效果）。

⚠️ **注意**：誤點成"無顏色"會讓物體看起來"沒上色/發暗"，不是壞了，再選個正常色即可。

✏️ **練一練**：用 HEX 輸入你喜歡的某個顏色（如 `#ff6b6b`），填到立方體上；再用吸管從頁面某處取色，對比兩者。

## 第20章 上傳圖片貼圖與不透明度

### 20.1 上傳圖片：把照片貼到表面

除了預設花紋，你還能**上傳自己的圖片**（PNG/JPG）作為表面貼圖——公司 Logo、照片、手繪都行。貼上去後，物體表面就"印"上了這張圖。

- 適合：做帶真實照片的展板、印 Logo 的獎牌、貼地圖的地面；
- 貼士：圖最好方正、清晰，貼在 box 正面最清楚。

### 20.2 不透明度（opacity）

右面板能調"不透明度"：

1 = 完全實心；
0.1 = 幾乎看不見；
中間值 = 半透明（玻璃、幽靈、水感）。

💡 做"玻璃罩""冰""幻影"全靠它。半透明時，後面的物體會透出來，層次感立刻豐富。

### 20.3 組合拳

- 花紋 + 半透明 = 朦朧的紗；
- 純色 + 高透明 = 玻璃磚。

# 第五篇 文本與圖片篇

場景裡除了形狀，還需要"字"和"照片"來傳達資訊。本篇講文本與圖片兩種"內容型"物件。

## 第21章 新增文本：讓場景會說話

### 21.1 文本是"會說話的薄板"

標牌、名稱、提示、標語……文字讓三維場景有了語義。文本物件本質是一塊"貼了字的薄平面"，能像普通物件一樣被選中、移動、旋轉、縮放、上色。

### 21.2 三步加上文本

1. 左面板「工具」裡選「新增文本」；
2. 在中央地面點一下，彈出**輸入框**（佔位提示為「輸入文本······」）；
3. 輸入文字，按 **Enter** 確認，文字落到地面；輸入框內按 **Shift + Enter** 可換行（多行文本）。

💡 佔位提示「輸入文本······」只是提醒你"在這裡打字"，本身不是內容；它不會出現在最終作品裡。

### 21.3 改內容：雙擊

放好後想改字？**雙擊**文本物件，輸入框重新彈出，改完回車即可。無需刪了重加。

### 21.4 文本也是完整物件

文本支援全部常規操作：選中、平移（藍前後/紅左右/綠升高）、旋轉、縮放、改顏色、調不透明度。做"發光字""半透明字"都行。

✏️ **練一練**：加一行"歡迎"，移到場景入口；再雙擊改成"歡迎光臨"，體會即時編輯的順手。

## 第22章 字型、字號、粗細與橫豎排

選中文本後，右面板出現文本專屬控制元件。本工具提供 **8 種字型**與若干排版開關。

### 22.1 八種字型怎麼選

| 字型 | 氣質 / 用途 |
| --- | --- |
| 雅黑 | 現代、清晰，中文預設首選 |
| 宋體 | 正式、書卷氣 |
| 楷體 | 手寫感、傳統、匾額 |
| 黑體 | 厚重、醒目標題 |
| 仿宋 | 公文、清秀 |
| Arial | 西文現代無襯線 |
| Times | 西文襯線，正式 |
| Courier | 西文等寬，程式碼/打字機感 |

💡 中文內容優先前五種；純英文可用後三種表現不同氣質。

### 22.2 字號（預設 80）

字號預設 **80**，可在右面板調整。太大容易"頂破"場景比例，太小看不清。

⚠️ **注意**：字號是相對場景單位的，要和你的圖形大小搭配——給一個 1.2 單位的立方體配 500 的字，字會比物體大得多。

### 22.3 粗細（粗體開關）

一鍵加粗，標題更醒目。配合黑體/楷體，做"牌匾感"很出彩。

### 22.4 橫排 / 豎排

- **橫排**：普通一行字，從左到右；
- **豎排**：從上往下排，適合中式匾額、書名、標牌。

💡 組合建議：豎排 + 楷體 + 大字號 = 傳統匾額；橫排 + 黑體 + 中等字號 = 現代標牌。

⚠️ **注意**：文本過長可能超出薄板寬度，可在輸入框內按 **Shift + Enter** 換行，或適當調小字號。

✏️ **練一練**：做一塊"茶館"豎排匾額（楷體、豎排、大字號、木質色），體會字型組合的"性格"。

## 第23章 圖片物件：把照片放進三維世界

### 23.1 新增圖片物件

左面板「工具」選「新增圖片」→ 選本地圖片檔案 → 地面點一下，圖片作為**平面貼片**出現（像一張立起來的照片）。

### 23.2 像普通物件一樣操作

選中後可移動、旋轉、縮放。能斜靠在牆上、能平鋪當地面裝飾、能舉高當招牌。

### 23.3 圖片也能當"貼圖"

第20章講過，圖片可"貼"到任意 3D 物件表面（作為表面材質）。所以同一張圖有兩種用法：

- **做獨立貼片**：作為場景裡的一張"照片"；
- **做表面貼圖**：印在 box / cylinder 等物體表面。

### 23.4 圖片 vs 2D 圖形

| | 圖片物件 | 2D 圖形 |
| --- | --- | --- |
| 內容 | 你自己的照片 / Logo | 軟體生成的形狀 |
| 能否改色 | 一般作為貼圖整體調 | 可改純色 / 花紋 |
| 典型用途 | 寫實照片、真實 Logo | 符號、地標、裝飾 |

兩者都"薄"，都能立能躺，按需選擇。

✏️ **練一練**：匯入一張你的照片，做"平面貼片"立在場景裡；再把同一張圖作為貼圖貼到一個 box 正面，對比兩種用法的差別。

# 第六篇 畫筆與橡皮篇

前兩篇講的是"標準形狀"，本篇講"徒手畫"——畫筆讓你像拿筆一樣在場景裡畫線，橡皮讓你擦掉它們。

## 第24章 2D 畫筆：在地面畫線

### 24.1 什麼是 2D 畫筆

2D 畫筆在**地面（XZ 平面）**上畫**平面線條**，像用筆畫在紙上。它適合畫地貼紋樣、路徑、塗鴉、地面指引。

### 24.2 怎麼用

1. 左面板「工具」選「2D 畫筆」；
2. 在中央地面**按住左鍵拖動**，鬆手即成一筆；
3. 可連續畫多筆。

### 24.3 按住 Shift 約束直線

拖動時按住 **Shift**，線條會被**約束成直線**（兩點間）。畫"筆直的路""規矩的邊"很好用。

> 方向鎖定：進入約束直線後，**這一筆（按住左鍵繪製）未結束前，方向始終鎖定為首次確定的水平 / 垂直 / 45° 方向**，即使中途滑鼠移動偏離也不會改變。想換方向，需鬆開左鍵另起一筆。

### 24.4 畫筆的四個屬性

右面板（畫筆啟用時）可設：

| 屬性 | 作用 |
| --- | --- |
| 顏色 | 線的顏色 |
| 粗細 | 線有多寬 |
| 不透明度 | 線實不實心 |
| 最小間距 | 取樣點之間的最小距離，越小越平滑、點越密 |

💡 "最小間距"越小，線條越細膩但頂點越多；越大越省、但折線感強。畫精細曲線調小，畫草圖可放大。

### 24.5 畫筆 vs 2D 圖形

- 2D 圖形是"標準形狀"（圓、心形…），可改色改花紋；
- 2D 畫筆是"你手繪的任意線"，自由但不規則。

想標準符號用圖形，想隨手塗鴉用畫筆。

✏️ **練一練**：用 2D 畫筆在地面畫一個"∞"符號，再按住 Shift 畫一條穿過它的直線，體會自由線 vs 約束線。

## 第25章 3D 畫筆與參考平面

### 25.1 3D 畫筆是什麼

3D 畫筆在**空間裡畫立體管道**——不是貼在地面，而是懸在空中的"管子線條"。它讓你可以"在空中畫畫"。

### 25.2 參考平面：第一筆決定"畫在哪一層"

3D 畫筆第一次點選時，會確定一張**半透明的「參考平面」**。之後的拖動都參考這張平面，線條落在它附近。

💡 想畫**水平的線**？先切到「頂視」，點一下確定水平參考面；想畫**豎直的線**？切「正視 / 左視 / 右視」再確定豎直面。參考面的朝向，決定了你畫的"維度"。

### 25.3 在平面上繪製，Shift 約束直線

- 在參考平面上拖動自由畫；
- 按住 **Shift** 拖動，約束成直線（和 2D 畫筆的 Shift 約束一致，作用在空間管道上）。

> 方向鎖定：同上，Shift 約束直線後**這一筆未結束前方向鎖定**，中途不可改變，鬆手另起一筆才能換方向。

### 25.4 球帽封口

每筆兩端會自動加**球帽封口**，線條首尾圓潤不破口，像真實的管子上加了端蓋。

### 25.5 用途

- 隨手雕塑飄帶、連線、能量束；
- 給場景畫"動態的線"（比放標準體更有機）；
- 做抽象藝術、線路示意。

❓ **想一想**：3D 畫筆的"參考平面"概念，和畫家"先裱一張紙"是不是一回事？為什麼在三維裡尤其需要這張"虛擬的紙"？

✏️ **練一練**：切到「頂視」，用 3D 畫筆確定一個水平參考面，畫一條波浪線；再切「正視」另畫一條豎線，感受空間線條的維度差異。

## 第26章 橡皮擦：整體與區域性

畫錯了要能擦。本工具橡皮有兩種模式，行為不同，務必分清。

### 26.1 兩種模式在哪切

右面板橡皮屬性裡有「橡皮擦模式」：**整體擦除 / 區域性擦除**。

### 26.2 整體擦除（預設）

拖動橡皮圈，碰到誰就**刪掉整個物件**（整根畫筆、整個圖形）。這是"大刀闊斧"的清理。

💡 想快速清掉一整根 3D 筆跡或一整個圖形，用整體模式，圈住即刪。

### 26.3 區域性擦除

開啟「區域性擦除」後：

- **2D 筆跡**：只擦掉橡皮圈**相交的那一段**，其餘保留（精細修線）；
- **3D 筆跡**：同樣只擦掉橡皮圈**相交的那一段**軌跡點，其餘保留（2D 與 3D 筆跡都支援逐段區域性擦除）；
- **其它物件**（標準 3D/2D 圖形、文本、圖片）：仍刪除**整個物件**（整體刪）。

⚠️ **注意**：區域性模式只對"畫筆筆跡（2D 與 3D）"逐段擦；對標準圖形、文本、圖片，還是整物件刪。別指望用區域性模式"啃掉立方體一角"。

### 26.4 橡皮大小

用「橡皮擦大小」滑塊調橡皮圈半徑，精細修細節或大範圍清理都靠它。圈太小要擦很多次，太大容易誤刪鄰居。

### 26.5 擦錯能恢復

橡皮刪的物件，和別的操作一樣進歷史——按 `Ctrl+Z` 就能找回來。所以大膽擦。

✏️ **練一練**：用 2D 畫筆畫一條長曲線，先開「區域性擦除」擦掉其中一小段（其餘還在）；再切「整體擦除」圈住另一根筆跡，看它被整根刪除。對比兩種模式。

# 第七篇 視角與觀察篇

"換個角度看"，往往就明白了。本篇講怎麼觀察和固定你的觀察角度。

## 第27章 七種預設視角：換個角度看世界

### 27.1 為什麼需要切視角

人眼只有一個角度，容易誤判"前後左右、誰高誰低"。一鍵換視角，等於繞著作品走一圈。底欄有 **7 個視角按鈕**。

### 27.2 七種視角逐一

| 視角 | 你像在… | 看到的主平面（網頁標註） |
| --- | --- | --- |
| 透視 | 正常站著看 | 近大遠小，最自然 |
| 頂視 | 從正上方往下俯瞰 | X（藍/前後）× Y（紅/左右）平面 |
| 底視 | 從正下方往上看 | 同頂視，但翻面 |
| 正視 | 從正前方平視 | Y（紅/左右）× Z（綠/高度）平面 |
| 後視 | 從正後方平視 | 同正視，方向反 |
| 左視 | 從正左側平視 | X（藍/前後）× Z（綠/高度）平面 |
| 右視 | 從正右側平視 | 同左視，方向反 |

💡 記住網頁標註：**X 藍=前後、Y 紅=左右、Z 綠=高度**。頂視看到的是"前後 × 左右"（地面），正視看到的是"左右 × 高度"（立面）。

### 27.3 什麼時候用哪種

- **透視**：整體觀察、截圖展示；
- **頂視**：精確擺位、對齊一排物件（看地面俯檢視最準）；
- **正視/左視/右視**：檢查"正不正""齊不齊"，做對稱構圖；
- **底視/後視**：少見但能驗證"背面/底面"是否如預期。

❓ **想一想**：為什麼建築師畫"平面圖、立面圖、側立面圖"？這七種視角里，哪幾個對應這三種工程圖？

✏️ **練一練**：擺 3 個不同圖形，分別點頂視、正視、右視，觀察同一個場景在不同視角下的"樣子"差別。

## 第28章 隱藏輔助與全屏

### 28.1 隱藏座標軸與網格

頂欄有「座標軸」「網格面」「地面」三個開關：

- 隱藏座標軸：去掉那三根帶字母的箭頭；
- 隱藏網格：去掉地面方格；
- 切換地面：控制半透明基準面（物體落地的參考平面）的顯示與隱藏。匯出作品或追求純淨畫面時，可一併隱藏。

⚠️ **注意**：截圖 / 匯出展示圖前，建議**先隱藏座標軸與網格**，畫面更乾淨、更"成品感"。它們只是輔助，不影響作品本身。

### 28.2 全屏

| 形態 | 全屏方式 |
| --- | --- |
| 🖥️📱 **網頁版** | 點頂欄「全屏」按鈕；🖥️ 滑鼠端還可按 **F11**。進入的是**瀏覽器全屏**，頁面佔滿螢幕 |
| 💻 **PC 版** | 無「全屏」按鈕；按 **F11** 或標題欄「最大化」按鈕為**視窗最大化 / 還原**（非真正全屏） |
| 🤖 **Android 版** | **沒有全屏按鈕**——應用本身就是全屏執行的，無需切換 |

🖥️ 網頁·滑鼠端按 **Esc** 僅關閉控制元件 / 取消選擇，**不會**退出全屏；要退出全屏請再按一次 **F11** 或再點一次「全屏」按鈕。💻 **PC 版**按 **F11** 是最大化/還原，再按一次 **F11** 即退出該狀態（PC 無「全屏」按鈕）。

### 28.3 一個實用組合

> 要出一張乾淨展示圖：隱藏座標軸 + 隱藏網格 + 切透視 + （🖥️📱💻 可選）全屏 + 截圖。

✏️ **練一練**：做一個小場景，先隱藏座標軸/網格截一張"乾淨圖"；再顯示它們截一張"帶輔助線圖"，對比給別人的觀感差異。

## 第29章 為什麼要記快捷鍵：效率的複利

### 29.1 一個被低估的事實

請你做一個小實驗：在場景裡放一個立方體，然後用滑鼠把它的"右側屬性面板"裡"等比縮放"滑塊來回拖 10 次，再用鍵盤 `+` / `-` 鍵按 10 次。

你幾乎一定會發現：**鍵盤更快、更準、更不累。**

原因有三個：
1. **手不用離開鍵盤核心區**——眼睛盯著畫面，手指在字母鍵上，大腦不用在"看畫面→找面板→移動滑鼠→拖滑塊"之間反覆切換。
2. **有固定步長**——按一次方向鍵，物體就精確移動"0.1 個網格"，按 10 次就是正好 1 個網格。滑塊拖 10 次，你根本記不清挪了多少。
3. **可疊加、可撤銷**——每一步鍵盤操作都會進歷史棧（見[第32章](jump:第32章 滑動條/輸入框 與 Ctrl 組合鍵)），按錯了 `Ctrl+Z` 一下就回退；滑塊拖動則是一段連續變化，撤銷時往往"跳"得比較猛。

💡 **心法一句話**：滑鼠負責"選"和"畫"，鍵盤負責"改"和"調"。分工合作，效率翻倍。

### 29.2 快捷鍵也分"場合"

本工具的快捷鍵不是"全域性一個意思"，而是**看當前有沒有選中物件**：

| 當前狀態 | 方向鍵 / A D W S 在幹什麼 |
|---|---|
| **沒選中任何物件** | 動的是**相機**（你在繞著場景看） |
| **選中了物件** | 動的是**那個物件**（物體在場景裡挪/轉） |

同一個 `↑` 鍵，沒選東西時是"鏡頭往前推"，選了東西后是"物體往前走"。這一區別是整個快捷鍵體系的核心，務必先刻進腦子裡，後面才不會混亂。

❓ **想一想**：為什麼"沒選中時動相機"是合理設計？——因為此時你大機率是在"找角度、看全貌"，讓鍵盤直接平移/旋轉視角，比去拖空白處更精準（空白處拖動是連續、無步長的）。

### 29.3 先把"座標軸語言"複習一遍

本篇所有"沿 X / Y / Z 軸"的說法，都按**頁面標註**來記（這跟你在畫面裡看到的軸標籤一致）：

- **X 軸（藍色）= 前後方向**（藍≈"deep/縱深"）
- **Y 軸（紅色）= 左右方向**（紅≈"左右"）
- **Z 軸（綠色）= 高度方向，向上為正**（綠≈"高"）

> ⚠️ 提醒：這是"頁面標註軸"。程式碼內部用的是另一套（X紅Y綠Z藍、Y 向上），但你在介面上、在說明書裡、在幫助面板裡看到的，永遠是上面這套標註。記標註軸就夠了，別被內部實現干擾。

記住這張表，後面每一章都是在用它"造句"。

## 第30章 滑鼠與手勢操作：四種形態都講

本工具的"快捷操作"會**隨裝置自動切換**：

- 🖥️💻 **網頁·滑鼠 與 PC 版** → 顯示並使用「滑鼠相關操作」（30.1）；
- 📱🤖 **網頁·觸屏 與 Android 版** → 顯示並使用「手勢操作」（30.2）。

下面兩張表與應用內「設定 → 快捷操作」裡的"滑鼠相關操作""手勢操作"**完全一致**，請對照你手上的形態看。

### 30.1 滑鼠相關操作（🖥️ 網頁·滑鼠 / 💻 PC 版）

| 操作 | 說明 |

| 雙擊左鍵 | 編輯文本 |
| 長按左鍵 | 操作物件/控制元件 |
| 長按右鍵 | 視角旋轉 |
| 長按滾輪 | 視角平移 |
| 滑動滾輪 | 視角縮放 |

### 30.2 手勢操作（📱 網頁·觸屏 / 🤖 Android 版）

| 操作 | 說明 |
|---|---|
| 單指單擊 | 選擇物件/控制元件 |
| 單指雙擊 | 編輯文本 |
| 單指長按物件 | 加選/減選（等價 Shift 單擊） |
| 單指拖動物件 | 操作物件/控制元件 |

| 「全選」按鈕 | 選中所有物件 |
| 「框選」按鈕 | 開啟後單指拖拽框選物件 |

⚠️ 📱🤖 觸屏端只有 **Android 版**有"單擊返回鍵"這一行為（手機瀏覽器/系統的返回鍵會**離開頁面**或退出應用，不觸發此邏輯）。手遊外的網頁·觸屏請改用介面上的關閉按鈕與 `Esc` 等價操作（單指輕點空白取消選擇）。

### 30.3 滑鼠 ↔ 手勢 一一對應表

兩套操作本質上是同一件事的兩種輸入方式：

| 意圖 | 🖥️💻 滑鼠 | 📱🤖 手勢 |

| 選擇 | 單擊左鍵 | 單指單擊 |
| 編輯文本 | 雙擊左鍵 | 單指雙擊 |
| 加選 / 減選 | `Shift` + 單擊 | 單指長按物件 |
| 操作物件 | 長按左鍵拖動 | 單指拖動物件 |
| 視角旋轉 | 長按右鍵 | 單指拖動空白 |
| 視角平移 | 長按滾輪 | 雙指拖動 |
| 視角縮放 | 滑動滾輪 | 雙指捏合 |
| 全選 | `Ctrl + A` | 「全選」按鈕 |
| 框選 | 空白處直接拖拽 | 「框選」按鈕 → 單指拖 |

💡 只是"輸入器官"不同。觸屏端沒有鍵盤，這些手勢與兩個專屬按鈕就是你的全部"快捷操作"。

## 第31章 單鍵操作與 Shift 組合鍵

鍵盤快捷鍵有一個核心規則：**看當前有沒有選中物件**。下面兩張表與應用內「設定 → 快捷操作」的"單鍵操作""Shift 組合鍵"**完全一致**，直接對照使用。

### 31.1 單鍵操作

> 選取物件時：平移 0.1 網格（0.15 長度）/ 旋轉 5°；未選取時：視角平移 0.1 網格 / 旋轉 5°。

| 按鍵 | 選取物件時 | 未選取時 |
|---|---|---|
| `↓` / `↑` | 沿 X 軸 +/− 平移 | 視角後 / 前平移 |
| `→` / `←` | 沿 Y 軸 +/− 平移 | 視角右 / 左平移 |
| `PgUp` / `PgDn` | 沿 Z 軸 +/− 平移 | 視角上 / 下平移 |
| `A` / `D` | 繞 Z 軸順 / 逆旋轉 | 視角左 / 右旋轉 |
| `W` / `S` | 繞 Y 軸順 / 逆旋轉 | 視角上 / 下旋轉 |
| `E` / `Q` | 繞 X 軸順 / 逆旋轉 | — |
| `+` / `-` | 放大 / 縮小 5% | — |
| `Esc` | 取消操作 | 關閉控制元件 |
| `F11` | 🖥️📱 全屏 / 退出全屏；💻 最大化 / 還原 | （同上） |
| `Del` / `Backspace` | 刪除選中物件 | — |

✏️ **練一練**：放一個立方體 → 選中它按 `↑` 看它"往前走"；取消選擇（點空白處）再按 `↑`，這次是鏡頭往前推。同一個鍵，兩種身份。

### 31.2 Shift 組合鍵

> 選取物件時：平移 1 網格（1.5 長度）/ 旋轉 90°；未選取時：視角平移 1 網格 / 旋轉 90°。

| `Shift` + 按鍵 | 選取物件時 | 未選取時 |
|---|---|---|
| `↓` / `↑`、`→` / `←`、`PgUp` / `PgDn` | 平移 1 網格 | 視角平移 1 網格 |
| `A` / `D`、`W` / `S`、`E` / `Q` | 旋轉 90° | 視角旋轉 90° |
| `+` / `-` | 放大 ×2 / 縮小 ×0.5 | — |
| 單擊左鍵 | 加選物件（點選） | （同上） |
| 長按左鍵（畫筆工具） | — | 畫筆約束直線模式（繪製時筆跡約束為水平 / 垂直 / 45°，與 `Shift` 約束同一效果） |

💡 口訣：**普通鍵湊近，Shift 鍵到位**。先按方向鍵微調到差不多，再 `Shift`+方向鍵做最後一次 1 網格大跳瞬間對齊；旋轉同理，先 `A` 轉 5°，再 `Shift+A` 直接補到 90° 擺正。

## 第32章 滑動條/輸入框 與 Ctrl 組合鍵

### 32.1 滑動條 / 輸入框

當你把游標放在某個滑塊或數字輸入框裡時，下面的鍵會"改這個框裡的數字"，而不是操控物體——原快捷鍵**暫時失效**。這張表與應用內「設定 → 快捷操作」的"滑動條 / 輸入框"**完全一致**。

| 按鍵 | 滑動條 | 輸入框 |

| `→` / `←` | 增 / 減 | 移動游標 |
| `↑` / `↓` | 增 / 減 | 增 / 減 |
| `+` / `-` | — | 輸入正 / 負號 |
| `PgUp` / `PgDn` | 大幅增 / 減 | 向上 / 下滾動右欄 |

⚠️ 想用物件快捷鍵，先點一下畫面空白處或物體，讓焦點離開輸入框。

### 32.2 Ctrl 組合鍵

| `Ctrl` + 按鍵 | 組合鍵 |
|---|---|
| `A` | 全選 |

| `Z` | 撤銷 |
| `Y` | 重做 |
| `C` | 複製 |
| `V` | 貼上 |
| `D` | 克隆 |
| `Del` / `Backspace` | 清空場景（彈"確定清空場景？此操作可撤銷。"確認框，確認後清空；普通 `Delete`/`Backspace` 無 `Ctrl` 時只刪除已選中的物件） |

⚠️ `Ctrl + Del` 會一次性刪光所有物件，但**會彈出確認框**且清空操作**可撤銷**（按 `Ctrl + Z` 恢復）。仍建議清空前先 `Ctrl + S` 匯出備份。

### 32.3 綜合實戰：用純鍵盤搭一個"小燈塔"

把本篇所學串成一條流水線：

1. 從面板拖一個**圓柱**到場景（只能滑鼠拖，認了吧）；
2. 選中它，`Shift + PgUp` 幾次把它"長高"到合適位置；
3. `Ctrl + D` 克隆一個當"燈室"，`PgUp` 挪到柱頂；
4. `Shift + A` 把燈室轉正 90°（如果需要）；
5. `Ctrl + A` 全選，`Ctrl + S` 存檔；
6. 點"正視"按鈕擺正視角，`Ctrl + P` 截圖交付。

全程除了第 1 步放形狀，幾乎沒碰滑鼠面板——這就是"效率篇"的終點：讓雙手長在鍵盤上。

# 第九篇 變換篇：會"說話"的箭頭

> 第32章你用鍵盤把物體搬來搬去，已經很快了。但鍵盤有"固定步長"——它適合精確、重複的移動，卻不適合"憑手感拖到正好貼著另一個物體"這種活。
>
> 這一篇的主角，是選中物體後出現在它身上的那組**彩色箭頭 / 圓環 / 方塊**，行話叫"變換控制元件"（gizmo）。它讓你用滑鼠直接"抓"著物體拖。

## 第33章 初見變換控制元件：三件"抓握工具"

### 33.1 它什麼時候出現

只要你**選中了一個物件**（點一下它，出現選中框），物體中心就會浮出一組手柄。這就是變換控制元件。

它有三套"皮膚"，對應三種操作，由右面板「變換模式」區（一個帶 ⇔ ↻ ⤢ 三個方按鈕的小區）切換：

| 模式 | 按鈕圖示 | 手柄長相 | 幹啥用 |
|---|---|---|---|
| **平移** | ⇔ | 三根**箭頭** | 把物體搬來搬去 |
| **旋轉** | ↻ | 三個**圓環** | 把物體轉來轉去 |
| **縮放** | ⤢ | 三個**方塊**（角上的小立方） | 把物體放大縮小 |

預設進的是**平移**模式。想換模式，點對應的按鈕即可；切換時底部還會飄一下提示文字（"平移/旋轉/縮放"）。

💡 小知識：變換控制元件和鍵盤快捷鍵是**同一件事的兩種入口**——鍵盤是"精準步進"，控制元件是"自由拖拽"。倆可以混用：先用控制元件拖個大概，再用鍵盤 `↑` 微調幾格對齊。第36章會專門講它倆怎麼配合。

### 33.2 一個必須提前說清的"顏色陷阱"

⚠️ **全篇最重要的提醒，務必讀這一段。**

場景裡那三根**座標軸標籤**用的是"頁面標註色"：
- **X = 藍色 = 前後**
- **Y = 紅色 = 左右**
- **Z = 綠色 = 高度**

但變換控制元件手柄的著色，遵循的是 **three.js 程式碼軸慣例**（紅=X、綠=Y、藍=Z），和上面那套**顏色對不上**！所以你看到的手柄顏色，得這樣翻譯：

| 手柄顏色 | 它實際代表的程式碼軸 | 對應頁面標註軸 | 在畫面上意味著 |
|---|---|---|---|
| 🔴 紅手柄 | 程式碼 X | 頁面 **Y** | **左右**移動 / 繞左右軸 |
| 🟢 綠手柄 | 程式碼 Y | 頁面 **Z** | **高度**（上下）移動 / 繞高度軸 |
| 🔵 藍手柄 | 程式碼 Z | 頁面 **X** | **前後**移動 / 繞前後軸 |

> 記不住沒關係，記住一句：**手柄紅=左右、手柄綠=上下、手柄藍=前後**（按頁面標註理解）。別被它表面的紅綠藍騙去套"場景軸標籤的顏色"。

✏️ **練一練（驗證用）**：選中一個立方體，切到平移模式。先拖**紅色箭頭**，看物體是"左右"滑還是"前後"滑？——應該是左右。再拖**藍色箭頭**，是不是"前後"滑？用這個實驗把上表刻進腦子，後面所有旋轉/縮放的軸都不會亂。

### 33.3 拖手柄時，視角還能動嗎

能，而且這是本工具一個很舒服的設計：

- **左鍵拖手柄** = 操控物體；
- **右鍵拖** = 旋轉視角（相機轉）；
- **中鍵拖** = 平移視角；
- **滾輪** = 縮放視角。

也就是說，你左手按住右鍵轉個角度看看物體側面，右手（或同手換鍵）還能繼續拖手柄——視角和變換**互不打架**。再也不用"先退出變換、轉視角、再進來"那麼折騰。

## 第34章 平移模式：用箭頭"抓"著物體走

### 34.1 三種拖法

平移模式下，除了三根軸箭頭，控制元件還提供**兩個平面方塊**（貼在某兩根軸張成的平面上）。於是你有三種抓法：

1. **抓單根箭頭**（紅/綠/藍）→ 只能沿那一根軸直來直去，最精準，不會跑偏；
2. **抓平面方塊**（比如紅綠箭頭夾著的那個面）→ 在這個平面內自由滑動，同時受兩根軸約束；
3. 想完全自由地"貼著地面亂拖"？先切到對應平面再拖即可。

💡 經驗：要做"準確對齊"，永遠**抓單根箭頭**，別抓平面——平面容易把物體帶偏到你不想要的方向。

### 34.2 平面怎麼認（結合顏色陷阱）

平移模式裡的平面，是"相鄰兩根箭頭夾出的三角/方塊區域"。按第33.2節的翻譯：

- 紅箭頭（左右）+ 綠箭頭（上下）夾出的平面 = **左右×高度** 平面（物體的"側面"）；
- 綠箭頭（上下）+ 藍箭頭（前後）夾出的平面 = **高度×前後** 平面（物體的"正臉/背影"）；
- 紅箭頭（左右）+ 藍箭頭（前後）夾出的平面 = **左右×前後** 平面 = **地面**（物體"踩著"的平面）。

✏️ **練一練**：把物體放到地面上，抓"紅+藍"夾出的平面方塊拖動——它是不是乖乖貼著地面滑，既不升高也不沉下？這就是"在地面上平移"最穩的姿勢。

### 34.3 和鍵盤平移對照著學

| 想做的動作 | 用控制元件 | 用鍵盤（第32章） |
|---|---|---|
| 沿前後精確挪 0.1 格 | 抓**藍箭頭**拖 | `↑`/`↓` |
| 沿左右精確挪 0.1 格 | 抓**紅箭頭**拖 | `←`/`→` |
| 沿高度精確升/降 | 抓**綠箭頭**拖 | `PgUp`/`PgDn` |
| 大步挪 1 格 | 控制元件抓箭頭硬拖 | `Shift`+方向鍵 |

💡 口訣：**控制元件管"手感"，鍵盤管"精度"**。先用控制元件拖到八九不離十，再用鍵盤 `↑`/`←`/`PgUp` 微調幾格貼齊網格線。

## 第35章 旋轉模式：圓環決定"繞哪根軸轉"

### 35.1 三個圓環 = 三根軸的旋轉

切到旋轉模式（↻），物體上變成三個彩色圓環，每個圓環代表"繞那根軸轉"：

| 圓環顏色 | 程式碼軸 | 頁面標註軸 | 觀感（回憶第32章比喻） |
|---|---|---|---|
| 🔴 紅圓環 | 程式碼 X | 頁面 **Y**（左右軸） | 像**前撲/後仰**翻跟頭 |
| 🟢 綠圓環 | 程式碼 Y | 頁面 **Z**（高度軸） | 像**轉盤/陀螺**原地轉 |
| 🔵 藍圓環 | 程式碼 Z | 頁面 **X**（前後軸） | 像**向左倒/向右倒**側翻 |

⚠️ 注意圓環顏色和"繞哪根軸"的對應，同樣要套第33.2節的翻譯表——**紅圓環繞左右軸、綠圓環繞高度軸（最常用，擺正用）、藍圓環繞前後軸**。

### 35.2 抓圓環轉，和鍵盤 A/D/W/S/E/Q 是一回事

第32章你用鍵盤轉過物體，那裡說：
- `A`/`D` 繞**高度軸**（頁面 Z，豎直軸）轉；
- `W`/`S` 繞**左右軸**（頁面 Y）轉；
- `E`/`Q` 繞**前後軸**（頁面 X）轉。

對應到控制元件圓環就是：
- 鍵盤 `A`/`D` ↔ 拖**綠圓環**（高度軸）；
- 鍵盤 `W`/`S` ↔ 拖**紅圓環**（左右軸）；
- 鍵盤 `E`/`Q` ↔ 拖**藍圓環**（前後軸）。

✏️ **練一練**：選中一個有"正面"的物體，按 `Shift + A` 讓它轉整 90°（擺正），然後切到旋轉模式去拖**綠圓環**——你會發現手拖的也是繞同一根豎直軸轉，而且可以停在任意角度（鍵盤只能 5°/90° 跳，控制元件能停中間值）。這正好互補。

### 35.3 自由轉 vs 精準轉

- 控制元件圓環：能停在**任意角度**，適合"轉到看著舒服為止"；
- 鍵盤 `Shift`+字母：只能 **90°** 整跳，適合"必須擺正、必須直角"；
- 鍵盤普通字母：只能 **5°** 步進，適合"微調幾度"。

💡 實戰：先控制元件拖到大概角度 → 再用 `Shift+A`（綠軸）補到正 90°/180°，立體字、建築立面這類"要正"的活兒最常用。

## 第36章 縮放模式：方塊手柄與"等比"開關

### 36.1 方塊手柄：拉一根軸，還是整體脹

切到縮放模式（⤢），物體角上出現小立方手柄。拖單個方塊 = **只沿那一根軸拉長/壓扁**（比如把球壓成橢球、把柱子拉成高thin）；拖中心方塊 = 整體縮放。

| 手柄顏色 | 頁面標註軸 | 拖它的效果 |
|---|---|---|
| 🔴 紅方塊 | 左右（Y） | 變寬 / 變窄 |
| 🟢 綠方塊 | 高度（Z） | 變高 / 變矮 |
| 🔵 藍方塊 | 前後（X） | 變深 / 變淺 |

### 36.2 "等比縮放"鎖定：新手最該開的開關

右面板變換模式區下方有個勾選框 **「等比縮放」**（預設就勾著）。勾上時，無論你拖哪個方塊，物體都**整體等比例**放大縮小，不會被拉變形——這通常正是你想要的。

⚠️ 取消勾選，再拖單個方塊，物體就會"單向拉伸"變形。這有創意用途（比如壓扁的墊片、拉長的橫樑），但新手容易誤關後納悶"怎麼歪了"。拿不準就保持勾選。

### 36.3 和鍵盤縮放對照，以及"多選禁縮"

| 想做的 | 用控制元件 | 用鍵盤（第32章） |
|---|---|---|
| 整體放大 5% | 拖中心方塊（等比勾選） | `+` |
| 整體縮小 5% | 拖中心方塊 | `-` |
| 翻倍 / 減半 | 拖中心方塊硬拉 | `Shift`+`+` / `Shift`+`-` |
| 單向壓扁 | 取消等比，拖單方塊 | 鍵盤不支援 |

⚠️ **重要限制**：當你**一次性選中了多個物件**時，縮放模式會被**自動停用**（按鈕變灰，且若當時在縮放模式會自動跳回平移）。原因和鍵盤 `+`/`-` 多選禁縮一樣——幾個大小不同的物體強行一起縮放會很怪。

💡 那多選時怎麼統一調大小？兩條路：① 先 `Ctrl + A` 後用控制元件/鍵盤逐個處理；② 用「等比縮放」之外的辦法——比如把它們先編好組別，靠平移擺位而非縮放。

### 36.4 哪些時候變換控制元件"不讓你用"

除了多選禁縮放，還有幾種情況變換模式按鈕會變灰、不可點：

- 你正處於**畫筆 / 文本 / 橡皮擦**工具模式時（這些工具自己接管了點選，變換控制元件先讓位）；
- 正在**編輯文本**（內聯輸入框彈出時），變換按鈕臨時停用，輸完恢復；
- **文本物件**本身不支援等比縮放，選中文本會隱藏等比縮放相關控制元件並停用縮放模式，自動切回平移；圖片與畫筆筆跡都能正常縮放。

⚠️ 如果發現三個模式按鈕點不動、是灰的，先檢查：是不是還停在某個工具裡沒退出？按 `Esc` 或點頂部"選擇"類按鈕退出工具，變換控制元件就活了。

### 36.5 控制元件與數值框：雙向同步

右側「變換」區裡還有對應的**數字滑塊/輸入框**（位置、旋轉角度、縮放值）。它們和控制元件是**雙向同步**的：
- 你拖控制元件，數字框即時跟著變；
- 你直接在數字框裡輸精確值（比如旋轉填 `45`、縮放填 `2.5`），物體也立刻變。

💡 需要"絕對精確"（比如旋轉必須正好 30°、縮放必須正好 1.5 倍）時，**直接用數字框輸入**比拖控制元件靠譜得多。控制元件適合"找感覺"，數字框適合"卡數值"。

---

✏️ **本篇小結**：變換控制元件是鍵盤的"自由拖拽版"。記住三件事——① 它有平移/旋轉/縮放三種皮膚，對應箭頭/圓環/方塊；② **手柄紅=左右、綠=上下、藍=前後**（永遠按頁面標註翻譯，別被表面顏色騙）；③ 左鍵拖物體、右/中/滾輪管視角，三者不打架。下一篇我們講"組合與編組、對齊與分佈"，讓你從"會動單個物體"進階到"會擺一大群物體"。

## 第37章 一次選中一群：認識"選擇集"

### 37.1 為什麼要多選

前面你都是"點一個、改一個"。但真實創作往往是一堆東西：一排樹、一列燈、一地石子。如果 100 個逐個調，人先瘋了。

解決辦法：先把它們**一次性選進"選擇集"**，再統一操作。這就是多選的意義。

### 37.2 多選三法

| 方法 | 怎麼操作 | 適合場景 |
|---|---|---|
| **全選** | `Ctrl + A`，或觸屏點底部「全選」按鈕 | 想選中場景裡所有物件 |
| **加選 / 減選** | 按住 `Shift` 再點物件：點到沒選中的=加進去；點到已選中的=踢出去 | 挑出特定幾個（比如"這兩個燈 + 那棵樹"） |
| **框選** | 在空白處**按住拖動**，拉出一個虛線框，框內的物件被一次性選中 | 一片密集物件，懶得一個個點 |

✏️ **練一練**：放 5 個形狀散在場景裡。先 `Ctrl + A` 看是不是全亮 → 點空白處取消 → 按住 `Shift` 點掉其中 2 個（變灰）→ 再在空白處拖一個框，把剩下的 3 個框住。感受"選擇集"像一摞便籤，隨意增刪。

💡 框選的小細節：滑鼠拖空白處才出框；觸屏因為沒"空白處拖"的概念，專門做了個「框選」按鈕，開啟後單指拖拽即框選（開啟時底部會提示"框選模式"）。框選沒框中任意物件，也會輕輕提示你"框選未命中物件"，不會 silently 失敗。

### 37.3 選擇的"邊界情況"

- 點**空白處**（不拖）= 取消全部選擇；
- 框選時若框**完全空**，選擇集被清空（相當於"反選成無"）；
- 正在**編輯文本**或處於**畫筆/橡皮擦**工具時，選擇邏輯讓位給工具，多選暫時不可用。

❓ **想一想**：為什麼"Shift+點選"既能加又能減？——因為選擇集不是"開/關"二元，而是一個**集合**。點已存在的元素就該移除，點不存在的就加入。這套"切換"邏輯你之後在檔案管理器、郵箱裡到處都會遇到。

## 第38章 一群一起動：多選變換的"主控點"

### 38.1 看不見的"主控點"

當你選中**多個**物件，工具不會把控制元件掛到某個具體物體上（掛誰都不公平），而是在**這群物體的正中心**放一個**看不見的代理點**（程式碼裡叫 `multiTransformProxy`）。

你看到的變換控制元件（箭頭/圓環），其實是掛在這個"主控點"上的。你拖它，演算法會算出主控點移動/旋轉的**增量**，再**同步分發給每一個選中的物件**。

> 翻譯成人話：**你拖一個隱形的"總開關"，所有被選中的東西一起跟著動，且彼此相對位置不變。**

### 38.2 多選能做什麼

| 操作 | 多選時可用？ | 說明 |
|---|---|---|
| 一起**平移**（拖箭頭/平面） | ✅ 可用 | 整群沿某軸整體移動 |
| 一起**繞中心旋轉**（拖圓環） | ✅ 可用 | 整群繞群體中心轉，像撥弄一轉盤棋子 |
| 一起**縮放** | ❌ 停用 | 多選時縮放模式按鈕變灰，自動跳回平移 |

✏️ **練一練**：選中 3 個散開的物件 → 切到旋轉模式 → 拖**綠圓環**（繞高度軸）→ 看它們是不是像"被一隻手同時擰轉"、圍繞共同中心轉圈，且彼此間距不變。這就是"群旋"的快感。

### 38.3 為什麼多選不能一起縮放

⚠️ 這是個**有意為之的限制**，不是 bug：

- 幾個大小、形狀不同的物體一起等比縮放，結果往往很怪（大的變得巨大、小的縮成芝麻）；
- 所以工具在多選時**直接停用縮放模式**，逼你"要麼逐個縮，要麼先克隆再調"。

💡 替代方案：
1. 想讓一群"長得一樣大"——先 `Ctrl + D` 克隆出一排相同的，它們本來尺寸就一致，再逐個微調；
2. 真要整體縮放一群——可以**先全選、匯出 JSON、改數值再匯入**？太折騰。更實在的是：把它們當作"臨時群組"，用**個體縮放 + 統一偏移**擺好。

### 38.4 多選 + Shift 大步，照樣好用

第32章學的 `Shift` 大步（1 網格 / 90°）對多選**同樣生效**。選中一群后按住 `Shift` 拖方向鍵，整群一次跳 1 格，排陣列超好用（下一章就用它）。

## 第39章 量產：複製、克隆與"陣列"

做重複物時，永遠別手動畫第 2 個、第 3 個……用"複製/克隆"讓電腦替你生。

### 39.1 三種"生副本"的方式

| 按鍵 | 名字 | 特點 |
|---|---|---|
| `Ctrl + C` | 複製 | 把選中物件**存進剪貼簿**（不立刻出現） |
| `Ctrl + V` | 貼上 | 從剪貼簿**取出**，粘到原位置附近 |
| `Ctrl + D` | **克隆** | 一步到位：原地複製並**自動偏移一點** |

💡 **最常用的是 `Ctrl + D`**。它比"複製→貼上"少一步，而且克隆出的副本自動錯開一點，你立刻就能看到、立刻能再擺——做陣列的標配。

✏️ **練一練**：放 1 個立方體 → `Ctrl + D` 一下，是不是多出一個、且稍微錯開？→ 選中新那個 → 按 `→` 挪到下一個格子 → 再 `Ctrl + D` → 再 `→`……幾下就排滿一排。全程沒碰滑鼠面板。

### 39.2 用"克隆 + 鍵盤"擺出整齊陣列

沒有"對齊/分佈"按鈕？沒關係，用**網格步長**手動排，照樣齊：

1. 選一個物體，`Ctrl + D` 克隆；
2. 按方向鍵把它挪到**正好 1 格**處（預設步長 0.1 網格，按 10 下；或 `Shift`+方向鍵一下 1 格）；
3. 重複 `Ctrl + D` + 方向鍵，一排就出來了；
4. 排完一排，把整排 `Ctrl + A` 全選，`Shift`+方向鍵把"整排"大步挪到下一行，再繼續克隆——兩維陣列（方陣）也就有了。

💡 **排圓圈的技巧**：克隆一個 → 把它移到離中心固定半徑處 → 整群繞中心旋轉（第38章）→ 每轉一個角度克隆一次。轉幾圈，一個"環形陣"就出來了。這是手動版"分佈"。

### 39.3 複製貼上的邊界

⚠️ 兩個你可能踩的提示（工具會彈小字提醒）：
- **"變換進行中，無法複製/克隆"**：如果你正拖著控制元件（變換啟用），複製/克隆按鈕會暫時失效。鬆手（結束拖拽）後再按即可。
- **"請先選中物件再複製"**：沒選中任何東西時按 `Ctrl + C`，它會提醒你先選。剪貼簿為空時 `Ctrl + V` 也會提示"剪貼簿為空"。

❓ **想一想**：克隆和複製貼上，底層區別在哪？——克隆是"當場生成偏移副本"，不依賴任何中間儲存；複製貼上是"先存剪貼簿、再取用"，所以你能把 A 場景複製、切到 B 場景貼上（本工具剪貼簿是記憶體級，同頁面內通用）。理解這點，你就知道為什麼有時 `Ctrl + V` 沒反應——大概剪貼簿是空的。

## 第40章 儲存與分享：讓作品離開螢幕

辛苦搭的場景，關掉網頁就沒了？不會——本工具能**匯出**成檔案、**匯入**回來、**截圖**成圖片。

### 40.1 三個"存/取"鍵

| 按鍵 | 作用 | 產物 |
|---|---|---|
| `Ctrl + S` | 匯出場景 | 一個 **JSON 檔案**（場景的完整描述） |
| `Ctrl + O` | 匯入場景 | 讀回之前匯出的 JSON |
| `Ctrl + P` | 匯出影像 | 一張 **PNG 圖片**（當前畫面的照片） |

💡 工作流：**搭一段 → `Ctrl + S` 存檔 → 第二天 `Ctrl + O` 讀回繼續**。JSON 是你的"工程檔案"，PNG 是你的"成果照片"，倆分工。

### 40.2 JSON 裡到底存了啥

匯出的 JSON 不是圖片，而是一份**物件清單**，大致記錄：

- 每個物件的**型別/形狀**（是球還是字、長寬高參數）；
- 每個物件的**變換**（位置、旋轉、縮放——也就是它在哪、歪沒歪、多大）；
- 每個物件的**外觀**（顏色、花紋、透明度、貼圖）；
- 場景的**環境設定**（座標軸、網格面顯隱等）。

⚠️ 因為存的是"引數"而非"畫素"，所以你匯入後能**繼續編輯**——這不是一張死圖，而是活的工程。這也解釋了為什麼前面所有操作都能進"歷史棧"被撤銷：它們本質都在改這份引數。

### 40.3 分享與協作建議

- **給同事看效果**：發 PNG（`Ctrl + P`）最快；
- **讓同事接著改**：發 JSON（`Ctrl + S`），對方 `Ctrl + O` 開啟就能編輯；
- **跨裝置**：把 JSON 傳到網盤/微信，在另一臺電腦開啟網頁、匯入即可——場景隨身走。
- ⚠️ 別忘了 `Ctrl + Del` 是**清空整個場景**，會彈出"確定清空場景？"確認框、且清空可撤銷。清空前先 `Ctrl + S` 備份，別把心血一鍵蒸發。

### 40.4 手動"對齊與分佈"：沒有按鈕也能排齊

回到篇首的承諾——既然沒有一鍵對齊/分佈，這裡給三招**純手動**的整齊法，配合前面所學：

1. **靠網格**：預設移動步長 0.1 網格（=0.15 單位），按整數次 = 精確落在格線。`Shift`+方向鍵一次 1 格，最適合"貼齊網格線"。
2. **靠克隆**：如第39章，克隆 + 固定步長 = 等距陣列（這就是"分佈"）。
3. **靠視角**：先點底部「正視/頂視」把物體擺正到標準機位，再沿單一軸用鍵盤挪，避免"歪著排"。

✏️ **綜合練一練（本篇畢業作）**：用"立方體 + `Ctrl + D` 克隆 + `Shift`+方向鍵"擺出 5×3 的方陣；`Ctrl + A` 全選後 `PgUp` 整體升到離地一格；`Ctrl + S` 存檔。你現在已經能"批次生產 + 整齊排列 + 儲存成果"了。

## 第41章 專案一：搭一座小房子

### 41.1 先看成品，再想拆法

我們要做的東西很樸素：一間帶屋頂、門、窗的小房子，立在草地上。

先別急著拖圖形。請你花 10 秒想一個問題：

❓ **想一想**：一座房子，如果只能用"立方體、圓錐、正四稜錐、圓柱、平面"這幾種基本形狀拼，你會怎麼拆？

這是三維創作最核心的思維——**把複雜物體拆成簡單幾何體的組合**。專業術語叫"體塊分析"，但說白了就是"搭積木"。

參考拆法：

| 部件 | 用什麼圖形 | 為什麼 |
|---|---|---|
| 牆體（主體） | `box` 立方體 | 房子本質就是個盒子 |
| 屋頂 | `pyramid` 正四稜錐 | 方底尖頂，正好扣在方牆上 |
| 門 | `box` 壓扁的薄板 | 貼在牆面上，比 2D 圖形好擺 |
| 窗 | `box` 更小的薄板 | 同上，可調半透明當玻璃 |
| 煙囪 | `cylinder` 圓柱 | 細高，從屋頂探出來 |
| 地面草地 | `square2` 正方形 | 2D 平躺在地面，當草坪 |

💡 **心法**：任何造型都先問"它由幾個體塊構成"。哪怕做汽車、做機器人，思路完全一樣。

### 41.2 第一步：打地基（草坪）

1. 左面板切到 **2D 圖形**，拖一個 `square2` **正方形**到場景中央；
2. 選中它，右面板選**綠色系**顏色；
3. 花紋選 **方格**——遠看像修剪過的草坪紋理；
4. 用**等比縮放**（右面板滑塊或 `Shift + +`）把它放大到明顯比房子大一圈。

⚠️ **翻車點**：2D 圖形是"平躺在地面（Z=0）"的貼紙。如果你發現它"立起來"了，多半是不小心用旋轉控制元件轉過——按 `Ctrl + Z` 撤銷回去，別硬掰。

✏️ 順手練：按底部「**頂視**」按鈕，從正上方看一眼草坪範圍夠不夠大；再按「透視」回到常規視角。這種"換視角檢查"的習慣，本篇之後每一步都建議做。

### 41.3 第二步：立牆體

1. 切到 **3D 圖形**，拖一個 `box` **立方體**到草坪中央；
2. 選中，用 `PgUp` 把它抬到**剛好坐在地面上**（底面貼地，不懸空也不陷進去）；
3. 右面板改成**米色 / 淺黃**（牆體色）；
4. 花紋選 **磚牆**——瞬間從"一個方塊"變成"一面房子"。

💡 **判斷"貼地"的訣竅**：點底部「**正視**」按鈕，從正前方平視看過去，一眼就能看出物體是浮在空中還是陷進地裡。透視視角下容易看走眼，正視不會騙人。

⚠️ **翻車點**：很多新手在透視視角下調高度，怎麼調都覺得"怪怪的"。切正視，兩秒解決。

### 41.4 第三步：扣屋頂

1. 拖一個 `pyramid` **正四稜錐**；
2. 用 `PgUp` 把它升到**牆體正上方**，讓錐底剛好壓在牆頂；
3. 左右前後位置對不齊？用 `↑↓←→` 微調（0.1 格步長）；對不上大數就 `Shift +` 方向鍵跳一整格；
4. 顏色改**紅褐 / 深灰**（瓦色）。

❓ **想一想**：為什麼屋頂要用"正四稜錐"而不是"圓錐"？——因為牆是方的。方頂配方牆，邊緣才嚴絲合縫；圓錐扣方牆，四個角會露出來。**形狀的匹配，是"看著對不對"的關鍵。**

✏️ **練一練**：故意換成 `cone` 圓錐試一次，從正視和頂視各看一眼，感受"露角"的違和。然後 `Ctrl + Z` 換回來。

### 41.5 第四步：開門窗

門窗的做法是"**壓扁的薄板貼在牆面上**"：

1. 拖一個 `box`，先**取消勾選「等比縮放」**（第36.2 節），把它拉成**薄薄一片**；
2. 重新勾回等比縮放（防止後面誤拉變形）；
3. 用方向鍵把它**貼到牆的正面**——注意要稍微"探出"牆面一點點，否則會和牆"打架"（見下方翻車點）；
4. 顏色選**深棕**（木門）。

窗戶同理，做兩個小一點的薄板，顏色選**淺藍**，並把**不透明度調到 0.5 左右**——玻璃感立刻出來（第20.2 節）。

⚠️ **重要翻車點：Z-fighting（閃爍打架）**
如果門板和牆面**完全重合在同一平面**，你會看到它們閃爍、互相穿插——這不是 bug，是兩個面在同一深度"搶位置"。
**解決辦法**：用方向鍵把門往外挪一小步（1～2 次 0.1 格即可），讓它明確"浮"在牆面前方。

💡 做第二扇窗別重畫——選中第一扇，`Ctrl + D` 克隆，再用 `←` 或 `→` 挪到另一側。這就是第39章的克隆陣列在實戰裡的第一次出場。

### 41.6 第五步：加煙囪與收尾

1. 拖 `cylinder` **圓柱**，用等比縮放調細，`PgUp` 升到屋頂斜面上，讓它探出一截；
2. 顏色**深灰**；
3. 想更有生活氣？用 `sphere` 球體克隆幾個、堆在煙囪口當"煙"，並把不透明度調到 0.3。

**最後檢查清單**（每個專案都建議走一遍）：

| 檢查項 | 怎麼查 |
|---|---|
| 有沒有懸空 / 陷地 | 點「正視」平視看 |
| 前後位置有沒有穿模 | 點「左視」或「右視」看 |
| 整體佈局是否居中 | 點「頂視」俯瞰 |
| 成品好不好看 | 點「透視」回常規視角 |

確認無誤後：`Ctrl + S` 匯出 JSON 存工程，`Ctrl + P` 截一張 PNG 交作業。

### 41.7 進階挑戰

1. **做成一排聯排別墅**：全選整座房子（`Ctrl + A`）→ `Ctrl + D` 克隆 → `Shift +` 方向鍵整體挪開一格 → 重複三次。注意多選克隆時整組的相對位置不變（第38章的"主控點"機制）。
2. **換季**：把草坪花紋換成"圓點"、顏色換成白色 → 變雪地；牆體不透明度調到 0.4 → 變冰屋。
3. **加門牌**：用第21章的文本工具，在門上方加一行"1 號"，字型選**黑體**、字號調小到與房子成比例。

⚠️ 提醒：文本預設字號 **80**，而房子體塊通常只有 1～2 個單位——直接加字會得到一個"比房子還大的巨型字"。必須把字號調小（或把文本整體縮小）才協調。這是新手做標牌時最常見的挫敗點，別慌，改字號就行。

## 第42章 專案二：製作立體字標語

### 42.1 目標與思路

做一塊**立在場景裡的標語牌**：底板 + 文字 + 裝飾，比如"歡迎光臨""開業大吉"或一句你喜歡的話。

⚠️ 先說清一個容易誤會的點：本工具的文本是「**貼了字的薄板**」（第21.1 節），不是真正帶厚度的立體擠出字。所以我們要的"立體感"，靠的是**底板 + 文字 + 錯層擺放**這套組合拳，而不是靠文字本身的厚度。

理解了這點，思路就清晰了：

| 層次 | 用什麼 | 作用 |
|---|---|---|
| 背板 | `box` 壓扁的薄板 | 給文字一個"依託面" |
| 主文字 | 文本物件 | 內容主體 |
| 影子字 | 文本物件（深色，往後錯一點） | 製造厚度錯覺 |
| 支架 | 兩根 `cylinder` | 讓牌子"站"在地上 |

### 42.2 第一步：做背板

1. 拖一個 `box`，取消「等比縮放」，壓扁成一塊**豎直的薄板**（寬 > 高 > 厚）；
2. 重新勾回等比縮放；
3. 用 `PgUp` 把它抬到眼睛高度（離地一段距離，別貼地）；
4. 顏色選**深色**（深藍 / 墨綠 / 木色都行）——深底配淺字最清楚。

💡 **配色原則**：文字和底板必須有**明度差**。深底淺字、淺底深字，兩者選一。同明度的搭配（比如中灰底 + 中綠字）遠看會糊成一團，這是設計裡最基礎也最常被忽略的規則。

### 42.3 第二步：打上文字

1. 左面板「工具」→「**新增文本**」；
2. 在場景裡點一下，彈出輸入框（佔位提示「輸入文本······」）；
3. 輸入你的標語，按 **Enter** 確認；
4. 選中它，右面板調：
   - **字型**：想現代用「黑體」，想傳統用「楷體」；
   - **字號**：預設 80，通常要**調小**才能配上體塊（見 41.7 的提醒）；
   - **粗體**：標語類建議開啟，遠看更醒目；
   - **顏色**：選和背板對比強的淺色。

5. 用方向鍵把文字挪到背板**正前方**，並記得往外探一點（防 Z-fighting，同 41.5 節）。

✏️ **練一練**：輸完字後**雙擊**它（第21.3 節），把內容改成另一句話。體會"不用刪了重來"的順手——這在反覆推敲文案時非常省事。

### 42.4 第三步：做"影子字"製造厚度

這是本章的核心技巧，很簡單卻效果拔群：

1. 選中主文字，`Ctrl + D` **克隆**一份；
2. 把克隆出的這份改成**深色**（比背板還深一點，或純黑）；
3. 用方向鍵把它**往後、往下各挪 1～2 小步**（0.1 格步長足夠）；
4. 如果它蓋住了主文字，說明前後關係反了——把主文字再往前挪一步即可。

現在從透視視角看過去：深色字在後、亮色字在前，**視覺上就"浮"起來了**。這是平面設計裡的"投影法"，在三維裡同樣奏效。

❓ **想一想**：為什麼"往後 + 往下"錯位比"只往後"效果好？——因為現實中光通常從**上方**打下來，影子自然落在物體的**下方偏後**。符合日常光照經驗的錯位，大腦才會認為它"真實"。

💡 想更強的立體感？把影子字**再克隆兩三份**，每份依次往後錯開一點、顏色逐漸加深——就成了"多層擠出"的假厚度效果。層數越多越厚重，但也越容易糊，3 層左右最討巧。

### 42.5 第四步：加支架，讓牌子站住

1. 拖兩個 `cylinder` **圓柱**，等比縮放調細調長；
2. 用 `PgUp` / 方向鍵把它們插到背板**下方兩側**，上端插進背板裡一點（這裡**故意穿插**是對的，能藏住接縫）；
3. 顏色選**深灰 / 木色**。

💡 第二根柱子別重新拖——選中第一根 `Ctrl + D` 克隆，再用 `←` / `→` 挪到另一側。**對稱的東西一律用克隆，永遠比手擺更準。**

### 42.6 第五步：橫排 vs 豎排

同一句話，換個排版氣質完全不同：

| 組合 | 氣質 | 適合 |
|---|---|---|
| 橫排 + 黑體 + 粗體 | 現代、商業 | 店招、活動橫幅 |
| 豎排 + 楷體 + 大字號 | 傳統、莊重 | 匾額、書院、茶館 |
| 橫排 + Times + 不加粗 | 西式、正式 | 英文標識、說明牌 |
| 橫排 + Courier | 技術、復古 | 科技感、打字機風 |

✏️ **練一練（對比實驗）**：把同一句"茶"字做兩版——一版橫排黑體，一版豎排楷體大字號 + 木色背板。並排放在場景裡，從「正視」看一眼。你會直觀感受到：**字型和排版本身就在說話**，內容還沒變，氣質已經天差地別。

### 42.7 常見翻車點彙總

| 現象 | 原因 | 解法 |
|---|---|---|
| 字大得離譜，蓋住整個場景 | 字號預設 80，與體塊尺度不匹配 | 調小字號，或整體縮放文本物件 |
| 字和背板閃爍互穿 | 兩者共面（Z-fighting） | 方向鍵把字往外挪 1～2 步 |
| 遠看糊成一片 | 字與底板明度差不夠 | 加大明暗對比，或給字加粗 |
| 文字超出背板邊緣 | 文案太長 | 調小字號，或把背板拉寬 |
| 改不了字號 / 方向鍵失靈 | 游標還停在數值輸入框裡 | 先點一下畫面空白處（第32.1 節） |

### 42.8 進階挑戰

1. **做一個雙面招牌**：把整組（背板 + 字 + 影子）全選後克隆，用 `Shift + A` 轉 180°，擺到背面，做成兩面都能看的立式招牌。
2. **發光字效果**：把主文字顏色調成亮黃，背板調成深黑，再在字後面放一個半透明（不透明度 0.3）的淺黃薄板當"光暈"。
3. **和專案一聯動**：把這塊招牌擺到第41章小房子的門前，`Ctrl + S` 存成一個完整場景。你現在有"房子 + 招牌"的完整小景了。

## 第43章 專案三：設計一枚徽標 / 圖示

### 43.1 為什麼徽標是"最好的練習題"

前兩個專案都在做"三維的東西"。這一個反過來——我們要做一枚**看起來像平面設計**的徽標，但用三維手段實現。

它是極好的練習題，因為：
- 只用 **2D 圖形**（第12章那 20 種）就能完成，形狀負擔小；
- 強迫你思考**對齊、層次、配色**這些真正的設計問題；
- 成品用「**頂視**」一截圖就是一張乾淨的圖示，可直接當頭像 / Logo 用。

❓ **想一想**：你見過的徽標（車標、校徽、App 圖示），大多由幾個元素構成？——通常不超過 3～4 層：底形 + 主圖形 + 點綴 + 文字。**少即是精緻**，這是徽標設計的鐵律。

### 43.2 關鍵前提：用頂視工作

⚠️ 本專案請**全程在「頂視」視角下操作**（底部視角按鈕）。

原因：徽標是"看正面"的平面構成，而 2D 圖形全都平躺在地面（Z=0）。從正上方俯視，你看到的就是成品的樣子；在透視視角下會有近大遠小的變形，對齊全靠猜。

💡 這是一個通用經驗：**做什麼，就用什麼視角看。** 做地面佈局用頂視，調高度用正視，看整體效果用透視。別用一個視角硬扛全程。

### 43.3 第一步：底形（最外層）

1. 左面板切 **2D 圖形**，選一個當底：
   - `circle2` 圓 → 圓形徽章，最百搭；
   - `hexagon` 六邊形 → 科技、工業感；
   - `octagon` 八邊形 → 穩重、標識感；
   - `pentagon` 五邊形 → 盾牌、學院感。
2. 放到場景**正中央**；
3. 等比放大到合適尺寸；
4. 顏色選**深色**（深藍 / 墨綠 / 酒紅都很出彩）。

### 43.4 第二步：內層與主圖形（做出層次）

徽標的精緻感，八成來自"**同心的層次**"。

1. 選中底形，`Ctrl + D` **克隆**一份；
2. 把克隆件**等比縮小**（`-` 鍵按幾下，或 `Shift + -` 減半）；
3. **關鍵**：用 `PgUp` 把它抬高**一小步**——讓它浮在底形上方一點點；
4. 換一個**淺色**（白 / 米 / 亮金）。

現在你有了"深色外圈 + 淺色內芯"的同心結構。

⚠️ **必踩的坑**：如果兩片 2D 圖形都在 Z=0，會瘋狂閃爍互穿（又是 Z-fighting，第41.5 節講過）。**2D 圖形疊層時，每一層都必須用 `PgUp` 抬高一小步**，讓它們在高度上分開。這是本章最重要的一條操作紀律。

💡 記住口訣：**每疊一層，就抬一步。** 三層圖形 = 三個不同高度。

接著放主圖形（徽標的"主角"）：

| 想表達 | 用哪個 2D 圖形 |
|---|---|
| 榮譽、評級 | `star` 五角星 |
| 喜愛、公益 | `heart` 心形 |
| 能量、快速 | `lightning` 閃電 |
| 醫療、救助 | `cross` 十字 |
| 方向、物流 | `arrow` 箭頭 |
| 自然、水 | `teardrop` 水滴 |
| 夜晚、靜謐 | `crescent` 月牙 |
| 科技、連線 | `hexagon` 六邊形 |

放上去、抬一步、調成對比色，居中對齊。

💡 提示：`heart / arrow / crescent / cross / lightning` 這幾種**都帶有獨立的形狀引數控制元件**（見第12.2 節，如心形的 `寬度/高度/心尖凹陷度`、箭頭的 `長度/寬度`、月牙的 `外半徑/內半徑/偏移量` 等），可直接調形狀。若只想整體改大小，也可用等比縮放或變換控制元件。

### 43.5 第三步：怎麼對齊到正中

本工具**沒有"一鍵居中"按鈕**（第十篇已交代過），但徽標恰恰最講究對齊。三招手動對齊法：

1. **靠網格**：在頂視下，地面網格線就是你的標尺。讓每一層的中心都對準**同一個網格交叉點**，用方向鍵（0.1 格）微調。
2. **靠克隆**：克隆出來的副本**只做等比縮放、不做平移**，它的中心就還在原地——天然同心。這是最省事的一招，強烈推薦。
3. **靠數值框**：右面板的位置數值框（第36.5 節）可以直接輸數。把每一層的水平位置都填成**同一組數字**，就是絕對精確的居中。

💡 **最佳實踐**：第 2 招 + 第 3 招組合。先克隆保證同心，最後用數值框複核一遍數字是否一致。比拖滑鼠可靠一百倍。

### 43.6 第四步：加文字環 / 底部文字

1. 「新增文本」，輸入品牌名或年份；
2. 字號**調小**（徽標裡的字通常很小）；
3. 字型：現代感用「黑體」，學院感用「Times」，傳統感用「宋體」；
4. 抬到**最上層**（比所有圖形都高一步）；
5. 擺到徽標下方或中間空白處。

⚠️ 本工具的文本**不能沿圓弧排列**（做不到"環形文字"）。想要類似效果，只能把文字拆成單字、逐個克隆並旋轉擺位——很費工。新手建議直接用**橫排文字放在底部**，同樣專業。

### 43.7 第五步：出圖

1. 點「**頂視**」，把徽標擺正在畫面中央；
2. 視需要按 `F11` 全屏，讓畫面更大更乾淨；
3. 想去掉干擾？把座標軸、網格面隱藏掉（第28章）——這一步很關鍵，否則截圖裡會有網格線；
4. `Ctrl + P` 截圖匯出 PNG；
5. `Ctrl + S` 存一份 JSON 工程，方便以後改配色。

💡 **出圖三件套**：頂視 + 隱藏輔助 + 全屏。任何需要"乾淨成品圖"的場合都這麼幹。

### 43.8 配色速查（拿去直接用）

| 風格 | 底色 | 內層 | 主圖形 | 文字 |
|---|---|---|---|---|
| 商務穩重 | 深藍 | 白 | 深藍 | 白 |
| 自然環保 | 墨綠 | 米白 | 綠 | 米白 |
| 活力運動 | 亮橙 | 白 | 深灰 | 白 |
| 高階奢華 | 純黑 | 金 | 金 | 金 |
| 醫療健康 | 白 | 淺藍 | 紅十字 | 深藍 |

⚠️ 新手最常見的配色錯誤是**顏色太多**。徽標控制在 **2～3 色**以內，立刻顯得專業。想豐富層次，靠**同一色相的深淺變化**（第18.2 節：固定色相條，只在大色塊裡上下拖），而不是多加顏色。

### 43.9 進階挑戰

1. **做一套系列圖示**：把徽標全選克隆三份，只改主圖形（星 / 心 / 閃電）、其餘全不動。你會得到一套風格統一的圖示——這正是真實品牌設計的做法。
2. **加浮雕感**：給主圖形克隆一份深色的、往一側錯開一小步、放在它下面一層（即 42.4 節的"影子字"技巧用在圖形上）。
3. **做徽章實體**：在整個徽標下面墊一個 `cylinder` 扁圓柱，切回透視視角——平面徽標立刻變成一枚"可以拿在手裡的金屬徽章"。

## 第44章 專案四：綜合場景《我的小院》

### 44.1 這一章是"畢業設計"

前三個專案各練一路本事：**體塊拼裝**（房子）、**文字排版**（標語）、**平面構成**（徽標）。這一章把它們**全部合到一個場景裡**，再加上畫筆、圖片、半透明等剩餘技能，做一個完整的作品。

目標：一座**帶院子的小屋**——房子、圍欄、小路、樹、水池、門牌、天空氛圍，一應俱全。

⚠️ 這是本書最長的一個練習，建議**分幾次做**，每做完一部分就 `Ctrl + S` 存一次盤。養成"階段性儲存"的習慣，比什麼技巧都值錢。

### 44.2 創作流程：先大後小，先定後飾

專業流程和新手最大的差別，不在手速，而在**順序**。請嚴格按這個順序做：

| 階段 | 做什麼 | 為什麼這個順序 |
|---|---|---|
| ① 定地面 | 鋪草坪、定院子範圍 | 先劃定"舞臺"，後面才有參照 |
| ② 擺主體 | 放房子（專案一的成果） | 最大的物體先定位，它決定整體比例 |
| ③ 劃分區 | 用畫筆畫出小路走向 | 在空地上規劃功能區 |
| ④ 加中件 | 樹、水池、圍欄 | 填充中等體量，豐富層次 |
| ⑤ 加小件 | 石子、花、門牌 | 細節最後加，避免早期干擾判斷 |
| ⑥ 調氛圍 | 顏色、不透明度、視角 | 統一調性，收尾出圖 |

❓ **想一想**：為什麼"細節最後加"？——因為細節會**干擾你對整體的判斷**。一堆小石子擺在那兒，你很難看清房子位置對不對。先把大關係定死，細節才有意義。這在繪畫裡叫"整體到區域性"，三維同理。

### 44.3 ① 鋪地面

1. 2D 圖形拖一個 `square2` 正方形，放大成院子地面；
2. 綠色 + 「方格」花紋 = 草坪；
3. 切「**頂視**」，確認範圍夠大——**寧可大一點**，後面東西越加越多，地方小了很難改。

💡 建議再鋪一塊更大的淺色底板在最外圈（記得 `PgDn` 讓它比草坪**低一步**，避免共面閃爍），當作"院子外的空地"，畫面會更有邊界感。

### 44.4 ② 擺房子

直接複用第41章的成果：

- 如果你存了工程，`Ctrl + O` 匯入進來；
- 沒存也沒關係，按 41.2～41.6 重搭一遍（這次會快很多）。

擺位建議：**別放正中央**。把房子放在院子的**偏後、偏一側**，前方留出大片空地——這樣構圖更自然，也給小路、水池留了地方。

💡 **構圖小知識**：把主體放在畫面正中，會顯得呆板；稍微偏離中心，反而更生動。攝影裡叫"三分法"，你可以借地面網格線來估位置。

### 44.5 ③ 用畫筆畫小路

這是畫筆工具（第24章）在實戰裡的經典用法：

1. 左面板「工具」→ **2D 畫筆**；
2. 調好顏色（土黃 / 淺灰）和線寬（粗一點，像條路）；
3. 從院子入口拖到房子門前，畫一條**微微彎曲**的線；
4. 畫完退出畫筆工具（按 `Esc` 或切回選擇）。

⚠️ **畫筆的兩條紀律**：
1. 畫筆筆跡畫完就"定"在那兒了，**不能像圖形那樣細調形狀**——畫歪了就 `Ctrl + Z` 撤銷重畫，別試圖修；
2. 畫筆筆跡的形狀**畫完即定型，不能像標準圖形那樣細調**（但筆跡物件本身支援整體縮放）。

💡 為什麼小路要"微微彎曲"而不是筆直？——筆直的線像圖紙，彎曲的線像生活。這個小細節能讓場景瞬間"有人味"。

✏️ **練一練**：先畫一條筆直的路，看一眼；`Ctrl + Z` 撤銷，再畫一條彎的，對比感受。這種"做兩版對比"的方法，是提升審美最快的路子。

### 44.6 ④ 加樹、水池與圍欄

**樹**（兩段式）：
1. `cylinder` 圓柱調細調長 → 樹幹，深棕色；
2. `sphere` 球體 → 樹冠，綠色，`PgUp` 放到樹幹頂上；
3. 選中樹幹和樹冠（`Shift` 加選，兩個都選中）→ `Ctrl + D` 克隆整棵樹 → 挪到別處。

💡 這裡用到了第38章的關鍵機制：**多選克隆時，兩個部件的相對位置保持不變**，所以複製出的是"一整棵完整的樹"，不會散架。種一排樹只要重複"克隆 + `Shift +` 方向鍵"。

⚠️ 別把所有樹做成一模一樣的大小——克隆後隨手用 `+` / `-` 給每棵微調 5% 左右的大小差異，自然感立刻上來。**規律中帶點隨機，是讓場景顯真的秘訣。**

**水池**：
1. 2D 圖形 `ellipse` 橢圓或 `circle2` 圓，平躺在地面；
2. `PgUp` 抬**一小步**（別和草坪共面）；
3. 顏色淺藍，花紋選「**波浪**」；
4. **不透明度調到 0.6** —— 半透明的水感就出來了（第20.2 節）。

**圍欄**（克隆陣列的教科書用法）：
1. `box` 壓扁成一根細長豎板 → 一根欄杆；
2. `Ctrl + D` 克隆 → `Shift +` 方向鍵挪一整格 → 再 `Ctrl + D` → 再挪……
3. 重複到排滿一邊；
4. 排完這一邊，`Shift` 全選整排 → `Ctrl + D` 克隆整排 → 用 `Shift + A` 轉 **90°** → 挪到院子另一邊。

💡 第 4 步是本書前十篇的集大成：**多選 + 克隆 + 整組旋轉 90°**，三個技能一次用上。做完這一步，你基本可以說"出師"了。

### 44.7 ⑤ 加細節小件

- **石子**：`sphere` 或 `dodeca` 十二面體縮小，克隆幾個撒在小路兩側，顏色灰系但**深淺各異**；
- **花**：`star` 五角星（2D）或小球，亮色，點綴在草地上；
- **門牌**：第42章的標語牌縮小版，掛在門口，寫門牌號；
- **照片牆**：用「新增圖片」放一張你自己的圖（第23章），當院子裡的展板。

⚠️ 細節要**剋制**。加到"看著豐富但不亂"就停手。判斷標準：切到「頂視」俯瞰，如果一眼看不出主次，說明加多了，刪掉一些。

### 44.8 ⑥ 調氛圍與出圖

**統一色調**（最能提升質感的一步）：

| 想要的氛圍 | 怎麼調 |
|---|---|
| 清晨 | 整體偏淺、偏冷（淺藍、米白），不透明度略高 |
| 黃昏 | 整體偏暖（橙、褐、金），加深陰影側的顏色 |
| 童話 | 高飽和（粉、青、亮黃），花紋用「圓點」 |
| 極簡 | 只用黑白灰 + 一個點綴色 |

💡 用第18.2 節的技巧統一色調：**固定色相條不動，只改明度和飽和度**，整個場景的顏色就會自動"和諧"。這是配色最省力也最有效的做法。

**出圖流程**（同 43.7）：
1. 底部試遍 7 個視角，挑最好看的一個（通常是「透視」略帶俯角）；
2. 隱藏座標軸和網格面（第28章），畫面立刻乾淨；
3. `F11` 全屏；
4. `Ctrl + P` 截圖；
5. `Ctrl + S` 存工程。

✏️ **最後一練**：給同一個場景截**三張不同視角**的圖——頂視（平面佈局圖）、正視（立面圖）、透視（效果圖）。這正是建築師交付方案的標準三件套。你已經能做出來了。

### 44.9 卡住時的自查清單

做大場景時最容易"越做越亂"。卡住了就按這張表自查：

| 症狀 | 多半是因為 | 怎麼救 |
|---|---|---|
| 越加越亂，不知道該幹嘛 | 沒按"先大後小"順序 | 停手，切頂視看整體，先把大件位置定死 |
| 東西互相穿插閃爍 | 共面（Z-fighting） | 用 `PgUp`/`PgDn` 把層次分開 |
| 比例失調，某物特別大 | 沒有參照物 | 放一個已知大小的物體當"標尺"，其餘照它調 |
| 顏色亂、顯廉價 | 顏色種類太多 | 砍到 3 色以內，靠深淺拉層次 |
| 選不中想要的物體 | 被別的物體擋住 | 換個視角再點，或先把遮擋物移開 |
| 方向鍵突然不動物體 | 沒選中 / 游標在輸入框 | 見第32.1 節排錯三連 |
| 一不小心全沒了 | 誤觸 `Ctrl + Del` 清空 | `Ctrl + Z` 撤銷；下次先存檔 |

### 44.10 結課語：從"會用"到"會做"

回頭看看你這一路：

- 第一篇你還在問"三維是什麼"；
- 第五篇你學會了讓場景說話；
- 第八篇你的手離開了滑鼠；
- 第十篇你能一次指揮一群物體；
- 現在，你獨立完成了一座帶院子的小屋。

工具的按鈕是有限的（20 種 3D + 20 種 2D + 12 種花紋 + 8 種字型），但**組合是無限的**。真正決定作品高度的，從來不是你會多少按鈕，而是：

1. **拆解能力**——能把複雜物體看成簡單幾何體的組合；
2. **順序意識**——先大後小、先定後飾；
3. **審美判斷**——知道什麼時候該停手。

這三樣，本篇的四個專案都在反覆訓練。剩下的，交給練習。

💡 **給你的下一步建議**：找一張你喜歡的照片（房間、街角、玩具），試著用本工具"復刻"它。做不像沒關係——**在"做不像"的地方，你會遇到真正屬於你的問題**，那才是進步開始的地方。

## 第45章 常見問題排查手冊

### 45.1 通用問題排查

下表按"你看到的現象 → 多半的原因 → 怎麼救"排列。絕大多數問題都有據可查，別急著懷疑是 bug。

| 序號 | 現象 | 多半原因 | 解決辦法 |
|---|---|---|---|
| 1 | 方向鍵、`+`/`−` 對物體沒反應 | 沒選中物件，或游標停在右面板數值輸入框裡 | 先點一下畫面空白處，確保選中了物體、且輸入框已失焦（第32.1節） |
| 2 | 兩個面閃爍、互相穿插 | 兩片共面（**Z-fighting**） | 用 `PgUp`/`PgDn` 把其中一片抬高/降低一步分開（第41.5、43.4節） |
| 3 | 文字大得蓋住整個場景 | 文本預設字號 **80**，遠大於體塊尺度 | 調小字號，或整體縮放文本物件（第21、41.7、42.3節） |
| 4 | 改了字號、方向鍵卻失靈 | 游標還停在數值輸入框裡沒出來 | 先點畫面空白處讓輸入框失焦（第32.1節） |
| 5 | `Ctrl+C`/`Ctrl+D`/`Ctrl+V` 沒反應 | 變換控制元件正啟用中，或未選中物件 | 先按 `Esc` 退出變換控制元件，再選中物件後操作（第33、39章） |
| 6 | 多選時按 `+`/`−` 被拒絕 | 多選時**禁止整體縮放**（提示"NoScaleMulti"） | 取消多選逐個縮放，或用變換控制元件拖手柄（第36.4節） |
| 7 | 選中文本後縮放模式被停用 | **文本不支援等比縮放**，自動切回平移 | 改文本大小請用「字號」引數（第21章）；圖片與畫筆筆跡均可正常縮放（第24、36.4節） |
| 8 | 畫筆/圖形畫歪了想改形狀 | 畫筆筆跡畫完即定型，不能像圖形細調 | `Ctrl+Z` 撤銷重畫（第24、44.5節） |
| 9 | 想居中卻找不到"居中"按鈕 | 本工具**沒有一鍵居中** | 三招：靠網格、靠克隆同心、靠數值框（第43.5節） |
| 10 | 文本想沿圓弧排（環形文字）做不出 | 本工具**不支援環形文字** | 用橫排文字放底部，或拆成單字逐個旋轉擺位（第43.6節） |
| 11 | 某些 2D 圖形（心/箭頭/月牙/十字/閃電）的形狀引數怎麼調 | 它們**各有獨立形狀引數**（心形 `寬度/高度/心尖凹陷度`、箭頭 `長度/寬度`、月牙 `外半徑/內半徑/偏移量`、十字 `長度/臂寬`、閃電 `高度/寬度` 等，見第12.2節） | 在右面板對應形狀引數裡直接調（第12.2、43.4節） |
| 12 | 誤刪了整個場景或重要內容 | 手滑 `Delete`，或清空了場景 | 立刻 `Ctrl+Z` 撤銷；並養成階段性 `Ctrl+S`（第44.1節） |
| 13 | 匯入 JSON 提示"載入失敗" | 檔案損壞，或不是本工具匯出的格式 | 確認用本工具的 `Ctrl+S` 匯出的 `.json`（第6章） |
| 14 | 視角按鈕不亮、相機轉了之後熄滅 | 自由旋轉後"透視"按鈕會熄滅（正常現象） | 點某個視角按鈕重新對齊即可（第28章） |
| 15 | 📱🤖 觸屏端拖動只會轉視角、框不出矩形 | 觸屏端框選需**先進入框選模式** | 先點底欄「框選」按鈕（變藍）再單指拖；**框完會自動退出**，要再框需再點一次（第7.4節） |
| 16 | 改了全域性顏色，某個物體卻沒變 | 該物體有**獨立顏色覆蓋**，或處於"無顏色"狀態 | 選中它單獨改色（第18章） |
| 17 | 螢幕取色器用不了 | 沒先啟用取色器工具 | 點調色區的取色器按鈕後再吸色（第18章） |
| 18 | 截圖裡有網格線/座標軸 | 沒隱藏輔助元素 | 隱藏座標軸和網格面再 `Ctrl+P`（第28、43.7節） |
| 19 | 克隆出的物體"散架"了 | 多選克隆前沒把一組都選中 | 用 `Shift` 把整個組合都選上再 `Ctrl+D`（第38章） |
| 20 | 旋轉視角/物體方向反了 | 記混了軸：`A/D` 繞 Z、`W/S` 繞 Y、`Q/E` 繞 X | 對著第47章速查表按，或 `Shift`+方向鍵大角度試（第32、34章） |

💡 **排查的第一性原理**：90% 的"不對勁"只有三個根因——**沒選中**、**游標在輸入框**、**兩片共面**。先默唸這三句，再對症查表，能省一半時間。

### 45.2 分端專屬問題

上表大多是四端通用的。下面這些只在特定形態出現：

**🖥️📱 網頁版**

| 現象 | 原因 | 解決 |
|---|---|---|
| 開啟是空白頁 | 頁面資源沒載入完，或瀏覽器過舊 | 重新整理；按 `F12` 看控制台紅色報錯；換 Chrome / Edge 新版 |

## 第49章 邊讀邊記：說明書裡的便籤

學習時，你常想在某個段落"做個記號"。說明書允許你在正文裡**選中一段文字 → 新增便籤**：

1. 在閱讀說明書時選中任意文字：
   - 🖥️💻 **滑鼠端**：按住左鍵**拖選**；
   - 📱 **網頁·觸屏**：長按文字即自動選中游標所在詞語，並彈出應用內「便籤 / 高亮 / 複製」浮層（可繼續拖動調整選區）；已禁用「超級拖放」與原長按選單（相容 MIUI / ColorOS / vivo 等國產 ROM），不再彈出系統複製 / 分享工具列；
     - 若所選文字與**已有高亮重疊**，浮層會改為顯示「取消高亮 / 擴充高亮」：點「擴充高亮」可把該高亮範圍擴展到目前選區邊界，點「取消高亮」則移除重疊部分的高亮。
   - 🤖 **Android 版**：長按文字會出現一個選區錨點和兩個可拖動手柄，拖動它們即可掃選文字；不再彈出系統複製/分享工具列，改由應用內「便籤 / 高亮 / 複製」浮層接管；
2. 鬆開後會冒出"新增便籤"按鈕，點一下；
3. 這段被選中的文字會被高亮，並記入**便籤列表**；
4. 便籤列表裡的每條都能單獨**刪除**——刪除前會彈出確認框，避免誤刪。

> 💡 便籤是"跟著文字走"的：它繫結在你選中的那句話上，方便你日後回看"我當時在想什麼"。

## 第50章 讓便籤"浮"在螢幕上

如果你不想來回翻便籤列表，可以把一條便籤**展開為懸浮便籤視窗**：

- 便籤視窗是一塊可拖動的浮動卡片，懸浮在畫布之上，不擋操作；
- 便籤視窗有**只讀**與**編輯**兩種狀態：只讀時像一張便利貼，編輯時可改文字；
- 不再需要時，點便籤上的關閉按鈕即可（`closeSticky`），它會從螢幕上消失，但便籤本身仍保留在列表裡。

### 50.1 便籤浮層與操作（四端一致）

便籤展開後是一塊**頁面內的置頂浮動卡片**（不是獨立系統視窗），四端行為一致：

- 它**始終置頂**，浮在畫布之上，方便邊看教程邊操作；
- 可拖動位置、可縮放視窗、可切換「置頂 / 取消置頂」（`manPin` / `manUnpin`）；
- 支援**最大化 / 還原**（`manMaximize` / `manRestore`）；
- 支援**匯出 / 匯入**便籤（`manExport` / `manImport`）、**全選**與**批次刪除**（`manSelectAll` / `manBatchDel`）；
- 通過「設定 → 快捷操作」裡列出的按鍵即可觸發上述操作（PC 版也可點視窗上的按鈕）。

> 📌 四端的便籤都是頁面內浮層，不能拖到應用視窗之外、也不能跨到別的程式之上。

### 50.2 關閉便籤的順序（📱🤖 觸屏端注意）

🤖 Android 版按**單擊返回鍵**時，會**先逐個關閉便籤**（若某條有未儲存內容，會先詢問你），再關目錄，再退出說明書，最後才詢問是否退出應用。

> 📌 便籤適合"臨時提示"：比如把某個引數說明貼在一旁，邊做邊看。

### 50.3 數量上限與批次管理

- **同時最多展開 5 個懸浮便籤**：超過時系統會**自動關閉最早開啟的那一個**，以保證效能與介面清爽。便籤本身仍保留在便籤列表裡，不會丟失。
- 便籤列表支援**批次刪除**：在列表中可一次勾選多條便籤並刪除（刪除前同樣彈確認框），不必逐條操作。

## 第51章 多語言：說明書也會"說"你的語言

介面與說明書都支援六種語言：

| 語言 | 介面 | 說明書 |
| --- | --- | --- |
| 簡體中文 | ✅ | ✅ |
| 繁體中文 | ✅ | ✅ |
| English | ✅ | ✅ |
| 日本語 | ✅ | ✅ |
| 한국어 | ✅ | ✅ |
| Русский | ✅ | ✅ |

切換方式：在設定裡選擇語言，介面文案與說明書正文會**同時**切換到對應語言版本。說明書的多語言內容分別存放在 `docs/使用說明書.md`（簡體）、`使用說明書_en.md`、`使用説明書_ja.md`、`使用說明書_zh-TW.md`、`사용설명서_ko.md`、`使用说明书_ru.md`。

💡 **語言是怎麼選出來的**：**首次啟動**時會**自動偵測系統語言**——依據系統／瀏覽器的語言設定，自動匹配簡體中文、繁體中文、English 或 日本語；之後你若手動切換過語言，軟體會**記住你的選擇並完全尊重**，不會再被系統語言覆蓋。也就是說，第一次用跟著系統走，日後你選什麼就用什麼。

✅ **六種語言 × 四種形態全部打通**：無論你用哪一端、選哪種語言，讀到的都是同一本經過三端適配的說明書。

> ⚠️ 關於刪除確認：所有刪除操作（便籤、場景物件）都走**自定義確認彈窗**而非系統原生彈窗，因此在**全屏 / 沉浸模式**下也能穩定彈出，不會"點了沒反應"。
